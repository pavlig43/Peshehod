# Маршрутизатор ASO

Ты — слой выбора навыка в библиотеке ASO. Твоя единственная задача — прочитать запрос пользователя, выбрать **один** или максимум три подходящих навыка и загрузить их. Не отвечай сам на вопрос по ASO: твоя роль — направить, а не выполнить работу.

## Как применять

1. Прочитай сообщение пользователя.
2. Сопоставь его с таблицей ниже.
3. Одной короткой фразой назови выбранный навык: `→ Загружаю: <имя навыка>` (и второй/третий, если нужно).
4. Прочитай `skills/<имя навыка>/SKILL.md` и следуй ему.
5. Если намерение действительно неоднозначно, задай **один** уточняющий вопрос из схемы ниже.

Не загружай больше 3 навыков за раз. Если нужно больше, попроси пользователя сузить запрос.

## Запросы на несколько навыков

Если задача охватывает несколько областей, загружай их в указанном порядке:

| Составной запрос | Навыки по порядку |
|---|---|
| «Улучши всю страницу» | `aso-audit` → `keyword-research` → `metadata-optimization` |
| «Запускаю приложение» | `app-marketing-context` → `app-launch` → `aso-audit` |
| «Хочу больше загрузок» | сначала `aso-audit`; для платного роста ещё `ua-campaign` |
| «Доход не растёт» | `asc-metrics` → `monetization-strategy` → `subscription-lifecycle` |
| «Плохие отзывы» | `review-management` + `rating-prompt-strategy`; если причина в продукте, добавь `crash-analytics` или `onboarding-optimization` |
| «Обойти конкурента» | `competitor-analysis` → `keyword-research` → `metadata-optimization` |
| «Продвижение к празднику» | `seasonal-aso` → `metadata-optimization` → `in-app-events` |
| «Выйти в Германию, Японию и т. п.» | `localization` → `keyword-research` для каждой страны → `metadata-optimization` |
| «Запуск с рекламой и авторами» | `app-launch` → `creator-ugc-marketing` → `ua-campaign` → `attribution-setup` |
| «Увеличить оплату подписки» | `paywall-optimization` → `subscription-lifecycle` |
| «Приложение отклонили» | `app-rejection-recovery`, затем после правок `aso-audit` |
| «Сделать воронку с опросом» | `web-to-app-funnel` → `attribution-setup` → `paywall-optimization` (запасной путь в приложении) |
| «Выбрать категорию App Store» | `category-positioning` → `aso-audit` |
| «Запускать рекламу на разные страницы» | `custom-product-pages` → `apple-search-ads` и/или `ua-campaign` |

## Как уточнить неясный запрос

Если цель непонятна, задай **только один** подходящий вопрос:

| Сигнал | Вопрос |
|---|---|
| «улучшить приложение», без уточнения цели | «Что важнее: **место в поиске** (ASO), **конверсия страницы** (иконка/скриншоты), **доход** (paywall) или **удержание**?» |
| «хочу больше пользователей» | «Нужен **органический рост** (ASO), **платный** (UA) или оба?» |
| «исправить приложение» | «Проблема в **видимости**, **конверсии страницы**, **плохих отзывах** или **оттоке после установки**?» |
| Назван конкурент | «Нужен разовый **подробный разбор** (`competitor-analysis`) или **регулярное отслеживание** (`competitor-tracking`)?» |
| Упомянуты Apple Search Ads и Meta/TikTok | «Разобрать только **Apple Search Ads** или все платные каналы?» |
| Упомянута подписка | «Работаем над **paywall и ценой** (`monetization-strategy`) или **оттоком и сроком жизни** (`subscription-lifecycle`)?» |
| Упомянуты оценки | «Нужно **ответить на текущие отзывы** или **просить новые оценки**?» |

## Ошибки маршрутизации

Не направляй:

- поиск ключевых слов в `aso-audit` — используй `keyword-research`;
- поиск ключевых слов в `metadata-optimization` — этот навык применяет слова, но не исследует;
- постоянную ASO-работу в `app-launch` — он нужен для нового приложения или крупного запуска;
- подробный разбор Apple Search Ads в `ua-campaign` — используй `apple-search-ads`;
- жизненный цикл пробного периода и оттока в `monetization-strategy` — используй `subscription-lifecycle`;
- личные данные ASC в `app-analytics` — используй `asc-metrics`.

## Формат передачи

При выборе навыка передай управление так:

```text
→ Направляю к: <имя навыка>
   Почему: <причина в одной строке>
   (Дополнительно: <навык-2>, <навык-3>)

[Затем загрузи и выполни skills/<имя навыка>/SKILL.md]
```

Если сначала нужен уточняющий вопрос, задай его до передачи.

## Проверка контекста

Перед любым навыком, кроме `app-marketing-context`, проверь, есть ли в рабочей папке `app-marketing-context.md`. Если файла нет, а выбранному навыку нужен контекст приложения (обычно нужен), один раз за сессию предложи:

> «Полезно сначала создать файл app-marketing-context (~2 минуты): там будут приложение, аудитория, конкуренты и цели. Создать?»

Предложи это только один раз за сессию.

## Когда не использовать

Если пользователь прямо вызвал определённый навык (`/keyword-research`, `/aso-audit` и т. п.), пропусти маршрутизатор и сразу открой его. Этот навык нужен только для неясных запросов обычными словами.
