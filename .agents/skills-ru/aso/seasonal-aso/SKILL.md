# Сезонная ASO-оптимизация

Помогай находить и использовать сезонные ключевые слова и изменения страницы, связанные с календарными событиями, праздниками и трендами.

## Главный принцип

**Сезонная выдача конкурентна и быстро меняется.** Метаданным нужно 1–3 дня для индексации. Планируй изменения за 2 недели до события, а через 3–5 дней после пика возвращай обычную версию.

## Сезонный календарь (iOS — США)

| Событие | Период пика | Ключевые слова |
|---------|-------------|----------------|
| Новый год | 26 декабря – 7 января | «new year», «resolution», «goals», «habit», «fresh start» |
| День святого Валентина | 1–14 февраля | «valentine», «love», «couples», «romantic», «gift» |
| Весна / Пасха | март–апрель | «spring», «easter», «refresh», «clean», «declutter» |
| День матери | 1–12 мая | «mom», «mother», «family», «gift for mom» |
| Лето | июнь–август | «summer», «vacation», «travel», «outdoor», «beach» |
| Снова в школу | 15 июля – 10 сентября | «school», «study», «student», «homework», «planner» |
| Хэллоуин | 1–31 октября | «halloween», «scary», «spooky», «costume», «trick» |
| Чёрная пятница | 20–30 ноября | «deal», «sale», «discount», «shopping», «gift» |
| Рождество | 1–26 декабря | «christmas», «gift», «holiday», «santa», «family» |
| Конец года | 27–31 декабря | «year review», «recap», «goals 2026», «new year» |

## Рабочий процесс

### Шаг 1 — выбери событие

1. Проверь `app-marketing-context.md`.
2. Спроси: **какое событие или сезон нужно использовать?**
3. Спроси: **что делает приложение?** — это нужно для проверки релевантности слов.
4. Определи, подходит ли событие. Не каждый сезонный повод применим к любому приложению.

### Шаг 2 — исследуй сезонные слова

Используй Appeeky, чтобы узнать объём сезонных запросов:

```bash
GET /v1/keywords/metrics?keywords=christmas+planner,holiday+tracker
GET /v1/keywords/suggestions?term=christmas&country=us
GET /v1/keywords/trending?country=us&days=7
```

**Фильтруй по:**
- всплеску объёма относительно базового уровня 30 дней назад;
- сложности ниже 60 (сезонные слова обычно перегружены);
- соответствию основной функции приложения.

### Шаг 3 — спланируй изменения метаданных

**Поле ключевых слов (100 символов, iOS):**
- замени слабые слова сезонными;
- добавь 2–4 сезонных слова, сохранив лучшие постоянные;
- убери сезонные слова, которые не связаны с функцией приложения.

**Подзаголовок (30 символов):**
- добавь сезонный крючок, если он уместен: «Your Holiday Planner» или «New Year Goal Tracker»;
- меняй его только если текущий подзаголовок не критичен для поиска.

**Рекламный текст (170 символов, проверка не нужна):**
- всегда обновляй его к сезонным событиям — изменения вступают сразу;
- используй сезонный призыв, краткое описание временной функции или связь с событием.

**Скриншоты:**
- добавь сезонную рамку или тему на первые 2 скриншота;
- для творческих решений используй навык `screenshot-optimization`.

### Шаг 4 — проверка сроков

```
План от даты события:
- [ ] T-14 дней: исследовать слова, подготовить творческое задание
- [ ] T-10 дней: написать новые метаданные и рекламный текст
- [ ] T-7 дней: отправить обновления скриншотов (проверка не нужна)
- [ ] T-5 дней: отправить обновления ключевых слов и подзаголовка
- [ ] T-0: пик события — ежедневно следить за позициями
- [ ] T+3 дня: вернуть постоянную версию метаданных
- [ ] T+5 дней: вернуть прежний рекламный текст
```

## Формат результата

### Описание сезонной возможности

```
🎄 Сезонная возможность: [название события]
   Период пика: [даты]
   Нужное время подготовки: [X дней]

Возможности ключевых слов:
  Высокий приоритет (всплеск объёма, сложность <60):
  - «[слово]» — объём [N], сложность [N]
  - «[слово]» — объём [N], сложность [N]

  Вторичный приоритет (релевантно, но конкурентно):
  - «[слово]» — объём [N], сложность [N]

Рекомендации по метаданным:
  Поле ключевых слов: [текущие] → [предложение — 100 символов]
  Подзаголовок: [оставить / изменить на: «...»]
  Рекламный текст: «[сезонный текст — 170 символов]»

Скриншоты: [предложить сезонную тему или оставить как есть]

Сроки:
  - отправить метаданные до: [дата]
  - отправить рекламный текст до: [дата]
  - вернуть прежнюю версию: [дата]
```

## Компромисс: сезонные и постоянные слова

| Фактор | Сезонные | Постоянные |
|--------|----------|------------|
| Объём | Временно очень высокий | Стабильный |
| Конкуренция | Очень высокая в пик | Средняя |
| Риск | Позиции упадут после пика | Стабильный результат |
| Выгода | Всплеск загрузок | Длительный рост |

**Правило:** заменяй только постоянные слова, которые уже плохо работают. Не жертвуй высокоранжируемым словом ради сезонной догадки.

## Тренды вне календаря

Для вирусных событий, новостей и трендов магазина:
1. Используй `GET /v1/keywords/trending?country=us&days=3`, чтобы найти новые слова.
2. Реагируй в течение 24–48 часов — окно короткое.
3. Обновляй только рекламный текст: он применяется сразу и не требует проверки.
4. Возвращай прежний текст, когда тренд уйдёт, обычно через 3–7 дней.
