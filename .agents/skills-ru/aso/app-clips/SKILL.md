# App Clips

Помогайте планировать, внедрять и улучшать App Clips — лёгкие части приложений для iOS размером до 15 МБ, которые можно запустить сразу, не ставя полное приложение.

## Что такое App Clips

App Clip — небольшая часть приложения с одной ясной задачей. Пользователь может открыть её без установки полного приложения. Такие части появляются:

- **в поиске App Store** — рядом с полным приложением;
- **в баннерах Smart App Banner** на сайтах;
- **через QR-коды и коды App Clip** — в том числе физические метки NFC/QR;
- **в Safari** — при переходе по связанной ссылке;
- **в «Сообщениях»** — когда ссылкой делятся через iMessage;
- **в «Картах»** — для местных компаний;
- **рядом с пользователем** — через метки NFC и видимые коды;
- **в подсказках Siri**.

## Ограничение размера

| Объект | Ограничение |
|--------|-------------|
| Файл App Clip | Не более **15 МБ** после уменьшения пакета; загружается по запросу |
| Полное приложение | Без изменений |

Поэтому в App Clip оставляют лишь самое нужное.

## Лучшие случаи применения

| Тип приложения | Что делает App Clip |
|----------------|---------------------|
| Парковка и транспорт | Оплата стоянки или покупка билета |
| Ресторан | Просмотр меню, заказ или оплата |
| Магазин | Просмотр товара или карта постоянного клиента |
| Фитнес | Одна пробная тренировка |
| Игры | Пробный уровень |
| Финансы | Калькулятор или быстрый расчёт предложения |
| Мероприятия | Покупка билета или регистрация на входе |
| Полезные инструменты | Разовое применение главной функции |

**Главный вопрос:** какой самый короткий сценарий покажет пользу приложения?

## Как App Clip находят в App Store

В **поиске App Store** App Clip показывается отдельной карточкой под полным приложением. На ней есть отметка «App Clip» и кнопка «Открыть» вместо «Загрузить».

- Нажав «Открыть», пользователь сразу запускает App Clip.
- После работы с ним он видит баннер с предложением загрузить полное приложение.
- Пользователи App Clip обычно ставят полное приложение в **3–5 раз чаще**, чем новые люди из обычного поиска.

**Вывод для ASO:** карточка App Clip берёт название и описание из данных основного приложения. Улучшая его страницу, вы также помогаете людям находить App Clip.

## Технические требования

### Что добавить в App Clip

- Только главный сценарий.
- Для входа и оплаты — «Вход с Apple» или Apple Pay, без полной регистрации.
- Никаких функций, доступных лишь в App Clip: всё из него должно быть и в полном приложении.
- Запрашивать только нужные разрешения; в App Clips нет push-уведомлений.

### Схема URL

Каждый App Clip запускается по ссылке:

```
https://yourdomain.com/clip/[experience]
```

Задайте её в App Store Connect → ваше приложение → App Clip Experiences.

### Переход к полному приложению

Всегда добавляйте понятное предложение установить полное приложение:

```swift
// Show SKOverlay after the user gets value from the clip
let config = SKOverlay.AppClipConfiguration(position: .bottom)
let overlay = SKOverlay(configuration: config)
overlay.present(in: windowScene)
```

Показывайте этот слой **после того**, как пользователь получил пользу, а не сразу при запуске.

## Варианты App Clip

Можно настроить несколько сценариев App Clip — по одному для каждого шаблона URL:

| Сценарий | URL | Назначение |
|----------|-----|------------|
| По умолчанию | `yourdomain.com` | Общий вход и поиск App Store |
| Место | `yourdomain.com/location/123` | «Карты» и NFC-метка в точке |
| Кампания | `yourdomain.com/promo/summer` | Рекламная кампания |
| Функция | `yourdomain.com/feature/x` | Показ отдельной функции |

У каждого сценария могут быть свои:
- название длиной до 18 знаков;
- подзаголовок длиной до 13 знаков;
- обложка 3000×2000 пикселей;
- текст кнопки действия.

## Оформление карточки App Clip

Пользователь видит карточку до запуска App Clip:

| Поле | Предел | Совет |
|------|--------|-------|
| Название | 18 знаков | Назовите действие: «Заказать кофе», а не имя приложения |
| Подзаголовок | 13 знаков | Покажите пользу: «Без очереди» |
| Обложка | 3000×2000 пикселей | Покажите результат, а не интерфейс |
| Кнопка действия | — | Выберите текст по задаче: «Заказать», «Оплатить», «Играть» |

## Оценка результата

Следите в App Store Connect → App Analytics → App Clips за:
- числом сеансов App Clip;
- числом показов карточек App Clip;
- переходами от App Clip к установке полного приложения;
- числом разных пользователей App Clip.

## App Clip и установка полного приложения

| | App Clip | Полная установка |
|---|---------|------------------|
| Усилия пользователя | Очень малы | Выше |
| Готовность остаться | Низкая | Высокая |
| Удержание | Низкое: обычно один запуск | Высокое |
| Переход от App Clip | — | В 3–5 раз чаще, чем из обычного поиска |
| Лучше всего подходит для | Знакомства и побуждения к установке | Удержания и дохода |

## Список для внедрения

```
Подготовка:
- [ ] Цель App Clip добавлена в проект Xcode
- [ ] App Clip меньше 15 МБ (проверьте отчёт о размере в Xcode)
- [ ] Настроено право Associated Domains
- [ ] Ссылки на сценарии App Clip внесены в App Store Connect

Удобство:
- [ ] Пользователь видит главную пользу за 60 секунд
- [ ] Для входа и оплаты есть «Вход с Apple» или Apple Pay, без своей формы регистрации
- [ ] SKOverlay появляется после полезного действия, а не сразу
- [ ] При установке полного приложения данные переходят понятным для пользователя образом

App Store Connect:
- [ ] Настроен сценарий App Clip по умолчанию
- [ ] Загружена обложка 3000×2000 пикселей
- [ ] Название не длиннее 18 знаков, подзаголовок — 13
- [ ] Если нужно, добавлены сценарии для мест и кампаний
```

## Связанные навыки

- `aso-audit` — видимость App Clip зависит от ASO основного приложения.
- `onboarding-optimization` — стройте сценарий App Clip по тому же правилу: сперва польза.
- `ua-campaign` — ведите людей на ссылки App Clip из платной рекламы.
- `app-store-featured` — App Clips могут помочь попасть в подборки App Store.
