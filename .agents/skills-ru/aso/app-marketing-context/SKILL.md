# Данные для продвижения приложения

Вы разбираетесь в продвижении мобильных приложений. Помогите пользователю собрать полный файл с данными, на который будут опираться другие навыки по ASO и продвижению.

## С чего начать

Проверьте, есть ли `app-marketing-context.md` в корне проекта или папке `.claude/`.

**Если есть:** прочитайте его и спросите, какие разделы пользователь хочет обновить.

**Если нет:** задайте вопросы по разделам ниже и соберите файл.

## Структура файла

Создайте `app-marketing-context.md` с такими разделами:

### 1. Сведения о приложении

```markdown
## Сведения о приложении
- **Название:** [название]
- **ID в Apple:** [числовой ID]
- **ID в Google Play:** [имя пакета, если есть]
- **Категория:** [главная категория]
- **Вторая категория:** [если есть]
- **Платформы:** [iOS / Android / обе]
- **Оплата:** [бесплатно / бесплатно с платными функциями / платно / подписка]
- **Дата выхода:** [дата или «ещё не вышло»]
- **Текущая версия:** [версия]
```

### 2. Польза для людей

Спросите пользователя:
1. Какую задачу решает приложение?
2. Кто его главный пользователь? Уточните возраст и другие важные признаки, привычки и нужды.
3. Чем приложение отличается от других решений?
4. Как описать его в одном предложении?

```markdown
## Польза для людей
- **Задача:** [какую проблему решает приложение]
- **Аудитория:** [кто его главный пользователь]
- **Главное отличие:** [чем оно выделяется]
- **Короткое описание:** [одно предложение]
```

### 3. Другие приложения

Спросите пользователя:
1. Какие 3–5 приложений — главные соперники?
2. Что у них сделано хорошо?
3. В чём они уступают?

```markdown
## Другие приложения
| Приложение | ID | Сильные стороны | Слабые стороны |
|---|---|---|---|
| [название] | [ID] | [сильные стороны] | [слабые стороны] |
```

### 4. Текущее состояние ASO

Если известен ID приложения, предложите взять его текущие данные из магазина:

```markdown
## Текущее состояние ASO
- **Название:** [текущее название]
- **Подзаголовок:** [текущий подзаголовок]
- **Поле ключевых слов:** [если известно]
- **Оценка:** [звёзды] ([число] оценок)
- **Главные запросы:** [запросы, по которым приложение находится высоко]
```

### 5. Цели и показатели

Спросите пользователя:
1. Какие три цели главные: загрузки, доход, удержание, места в поиске или что-то ещё?
2. За какими числами он следит?
3. К какому сроку хочет достичь целей?

```markdown
## Цели
1. [цель 1] — [показатель] к [дате]
2. [цель 2] — [показатель] к [дате]
3. [цель 3] — [показатель] к [дате]
```

### 6. Средства и ограничения

```markdown
## Средства
- **Бюджет:** [месячный бюджет на продвижение, если есть]
- **Команда:** [один человек / небольшая группа / группа продвижения]
- **Инструменты:** [аналитика, ASA, MMP и другие]
- **Ограничения:** [сроки, бюджет, техника и другое]
```

### 7. Рынки

```markdown
## Рынки
- **Главный:** [страна или регион]
- **Другие:** [страны или регионы]
- **Языки:** [языки приложения]
```

## Итог

Сохраните готовый файл `app-marketing-context.md` в корне проекта.

После этого кратко опишите:
- сильные стороны, на которые можно опереться;
- явные пробелы, которые стоит закрыть;
- навыки для следующего шага, например `aso-audit` или `keyword-research`.

## Связанные навыки

Все остальные навыки опираются на этот файл. Начинайте с него перед:
- `aso-audit` — полная проверка ASO;
- `keyword-research` — поиск ключевых слов;
- `competitor-analysis` — разбор других приложений.
