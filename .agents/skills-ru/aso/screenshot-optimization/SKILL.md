# Снимки экрана для App Store

Вы разбираетесь в том, какие картинки убеждают людей поставить приложение. Помогите создать снимки, которые повышают долю установок.

## С чего начать

1. Найдите `app-marketing-context.md` и прочитайте о месте приложения на рынке и его аудитории.
2. Спросите **App ID**, чтобы увидеть нынешние снимки.
3. Уточните **аудиторию**: кто ищет такое приложение в App Store?
4. Попросите назвать **три главные функции**, которые стоит показать.
5. Узнайте, есть ли **дизайнер** или пользователь будет делать снимки сам.

## Как люди смотрят на снимки

Человек проводит на странице приложения **3–6 секунд** до выбора. Первые три снимка, видимые без прокрутки, влияют на 80% решения об установке.

**Что люди хотят понять:**
1. «Решит ли это мою задачу?» — первый снимок.
2. «Легко ли этим пользоваться?» — ясность интерфейса.
3. «Стоит ли ставить?» — доверие и признаки качества.

## Схема снимков

### Место 1: главная зацепка

Первый снимок важнее всех. Он должен ответить: «Что делает приложение и зачем оно мне?»

**Рабочие приёмы:**
- **Заголовок о пользе + главный экран:** «Спите лучше уже сегодня» и экран учёта сна.
- **До и после:** покажите перемену.
- **Доверие + интерфейс:** «Нам доверяют более 5 млн человек» и главный экран.
- **Вопрос о проблеме:** «Надоело [проблема]?» и экран с решением.

**Избегайте:**
- пустого приветствия «Добро пожаловать в [приложение]»;
- экранов входа и регистрации;
- настроек и меню.

### Места 2–3: главная польза

Покажите две самые сильные функции с подписями о том, какую пользу они дают.

### Места 4–7: показ функций

Один снимок — одна функция и ясный заголовок о её пользе.

**Формула:** `[Заголовок о пользе] + [Экран функции] + [Поясняющая деталь]`.

### Места 8–9: доверие и отличие

- Награды, упоминания в прессе, оценки.
- Сравнение с другими решениями.
- Особые или платные функции.

### Место 10: призыв к действию

- «Начните бесплатный пробный срок».
- «К нам присоединились [X] млн человек».
- Кратко повторите главную пользу.

## Правила оформления

### Текст поверх снимков

| Делайте | Избегайте |
|---------|-----------|
| Заголовков о пользе | Одних названий функций вроде «Push-уведомления» |
| Заголовков по 4–6 слов | Длинных абзацев |
| Крупного, читаемого шрифта: хотя бы 60px | Мелкого текста |
| Высокого контраста | Текста поверх пёстрого фона |
| Единого шрифта и стиля | Смеси шрифтов и размеров |

### Картинка

| Делайте | Избегайте |
|---------|-----------|
| Чистого интерфейса без лишнего | Перегруженных данными экранов |
| Единой палитры | Несочетаемых цветов |
| Современной рамки устройства либо снимка без рамки | Рамки старого устройства |
| Настоящих данных приложения | Рыбного текста и пустых экранов |
| Тёмной темы, если она есть в приложении | Игнорирования людей с тёмной темой |

### Виды компоновки

**Вертикально — подходит большинству приложений:**
- устройство по центру, текст сверху или снизу;
- интерфейс во весь снимок и текст поверх;
- две части: текст слева, устройство справа.

**Горизонтально — игры, видео, рабочие приложения:**
- игра или содержимое во весь экран;
- мало наложенного текста;
- упор на действие.

### Перевод для других рынков

- Переведите текст поверх снимков для каждой страны.
- Подстройте местные образы и примеры.
- Для арабского и иврита продумайте компоновку справа налево.
- На снимках с ценой показывайте местную валюту.

## Видео предпросмотра

### Когда брать
- Для сложных приложений, чью работу нужно показать.
- Для игр — почти всегда полезно.
- Для приложений с необычным управлением.

### Правила
- **Зацепите в первые три секунды:** покажите самую сильную функцию.
- **Длина 15–30 секунд** обычно лучше всего.
- **Смысл должен быть ясен без звука:** добавьте субтитры и текст поверх.
- **Показывайте настоящую работу**, а не пустую рекламу.
- **Закончите призывом к действию**: «Скачать бесплатно» или главной пользой.

### Когда обойтись без ролика
- Простая полезная программа, для которой снимков хватает.
- Приложение, где важнее содержимое, а не сам интерфейс.

## Вид ответа

### План снимков

Для каждого из десяти мест:

```
Место [N]: [заголовок]
- Подпись: «[текст о пользе]»
- Экран: [какой экран приложения показать]
- Компоновка: [вертикально/горизонтально, рамка устройства, место текста]
- Главная деталь: [что притягивает взгляд]
```

### Задание дизайнеру

Если пользователю нужно дать задание дизайнеру, добавьте:
- палитру бренда;
- советы по шрифтам;
- образец компоновки;
- текст поверх для всех десяти мест;
- нужен ли вид устройства;
- стиль фона.
