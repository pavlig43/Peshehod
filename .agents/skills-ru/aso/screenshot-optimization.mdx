Скриншоты сильнее всего влияют на страницу приложения в App Store. Человек тратит лишь 3–6 секунд на решение о загрузке; первые три кадра, видимые без прокрутки, дают около 80% эффекта. Навык screenshot-optimization составляет план всех 10 кадров, готовые задания дизайнеру и сравнение с конкурентами.

**Вызов:** `/screenshot-optimization`

## Скриншоты влияют и на поиск, и на конверсию

Семантический поиск Apple индексирует видимый текст на скриншотах. Заголовки о пользе, подписи функций и призывы учитываются при поиске, а не только читаются людьми. Скриншоты с естественными ключевыми словами и ясной пользой работают сразу на загрузки и органическую видимость.

<Warning>
  Общие подписи вроде «Push Notifications» или «Easy to Use» тратят шанс на конверсию и место для слова. Каждый заголовок должен говорить о пользе и, когда это звучит естественно, включать целевой запрос.
</Warning>

## План 10 кадров

У каждого места своя задача:

<Steps>
  <Step title="Кадр 1 — крючок">
    Самый важный. Одной картинкой ответьте: «Что делает приложение и почему мне это нужно?» Хорошо работают заголовок о пользе на фоне главного экрана, сравнение «до/после» или социальное доказательство рядом с главным интерфейсом.

    **Не ставьте:** экран приветствия, входа, настроек или любой экран без мгновенно ясной пользы.
  </Step>
  <Step title="Кадры 2–3 — основная ценность">
    Покажите две самые сильные функции с подписями о пользе. Первые три кадра видны без прокрутки: вместе они должны убедить скачать.
  </Step>
  <Step title="Кадры 4–7 — функции">
    По одной функции на кадр по формуле `[Заголовок о пользе] + [Экран функции] + [Подробность]`. Вперёд ставьте то, что конкуренты не показывают.
  </Step>
  <Step title="Кадры 8–9 — доверие и отличие">
    Покажите награды, прессу, число людей, оценки и чётко скажите, что умеете только вы.
  </Step>
  <Step title="Кадр 10 — призыв">
    Завершите призывом («Начните бесплатный пробный период», «С нами уже 5 млн человек») или тремя главными плюсами. Напомните, зачем нажать **Загрузить**.
  </Step>
</Steps>

## Что создаёт навык

### План скриншотов

Для каждого из 10 кадров навык выдаёт структурное задание, которое можно сразу отдать дизайнеру или применить самому:

```text
Кадр 1: крючок
- Подпись: «Спите крепче — просыпайтесь бодрым»
- Экран: ночная панель отслеживания сна
- Макет: вертикальный, устройство в центре, заголовок сверху
- Главный элемент: кольцо с оценкой сна

Кадр 2: основная ценность №1
- Подпись: «Знайте, когда лучше лечь и проснуться»
- Экран: умный будильник с лучшим временем пробуждения
- Макет: вертикальный интерфейс на весь кадр, текст слева внизу
- Главный элемент: выделенное рекомендуемое время подъёма
```

### Задание дизайнеру

В полном задании есть:

- **палитра** из цветов бренда;
- **шрифты** и минимальные размеры для чтения;
- **макет** с обоснованием вертикальной или горизонтальной формы;
- **текст для всех 10 кадров** с подсчётом символов и упором на пользу;
- **рамка устройства** и стиль фона;
- **тёмная тема**, если она есть в приложении.

### Сравнение скриншотов конкурентов

Навык сравнивает вас с главными соперниками по шести признакам:

| Элемент | Ваше приложение | Конкурент 1 | Конкурент 2 | Конкурент 3 |
|---------|-----------------|-------------|-------------|-------------|
| Число скриншотов | | | | |
| Есть видео? | | | | |
| Тип первого кадра | | | | |
| Стиль текста | | | | |
| Качество дизайна (1–10) | | | | |
| Особый ракурс | | | | |

Сравнение находит пробелы: ваши функции, которых никто не показывает; ещё не занятый стиль категории; слишком частые приёмы, от которых лучше уйти.

## Правила дизайна

<Tabs>
  <Tab title="Текст поверх изображения">
    <CardGroup cols={2}>
      <Card title="Делайте" icon="check" color="#16a34a">
        - Заголовки о пользе для человека.
        - По 4–6 слов на заголовок — кратко и ясно.
        - Крупный читаемый шрифт (эквивалент не менее 60 px).
        - Сильный контраст текста и фона.
        - Один шрифт и стиль для всех 10 кадров.
      </Card>
      <Card title="Не делайте" icon="xmark" color="#dc2626">
        - Названия функций вместо пользы («Push Notifications»).
        - Длинные абзацы и подписи из нескольких предложений.
        - Мелкий текст, нечитабельный в миниатюре.
        - Текст на пёстром фоне без контраста.
        - Разные шрифты, толщины и размеры между кадрами.
      </Card>
    </CardGroup>
  </Tab>
  <Tab title="Внешний вид">
    <CardGroup cols={2}>
      <Card title="Делайте" icon="check" color="#16a34a">
        - Чистый интерфейс с одним центром внимания на кадр.
        - Единую цветовую схему бренда.
        - Современные рамки устройств или кадры без рамок для строгого стиля.
        - Подлинный контент приложения и реальные сценарии.
        - Кадры тёмной темы, если она есть.
      </Card>
      <Card title="Не делайте" icon="xmark" color="#dc2626">
        - Перегруженные данными экраны.
        - Несочетающиеся цвета и палитру вне бренда.
        - Старые рамки устройств, особенно до iPhone 15.
        - Заглушки, lorem ipsum и пустые экраны.
        - Игнорирование тёмной темы: многие смотрят магазин вечером.
      </Card>
    </CardGroup>
  </Tab>
  <Tab title="Ориентация">
    **Вертикальная (подходит большинству приложений)**

    Три рабочих макета:
    - устройство в центре, текст о пользе сверху или снизу;
    - интерфейс на весь кадр, текст всегда в одном углу;
    - деление: текст слева, устройство справа.

    **Горизонтальная (игры, видео, средства для работы)**

    - Игра или контент на весь экран.
    - Минимум текста, чтобы интерфейс говорил сам за себя.
    - Кадры с главным действием в самый яркий момент.

    <Tip>
      Первые три горизонтальных скриншота показываются в App Store крупнее. Это особенно полезно играм и другим приложениям, чей вид сразу привлекает внимание.
    </Tip>
  </Tab>
  <Tab title="Перевод для рынков">
    Каждый язык — отдельная проверка конверсии:

    - Переводите весь текст; не оставляйте английский в других странах.
    - Учитывайте местные культурные образы, фотографии и смысл цветов.
    - Разворачивайте макет для языков справа налево: арабского, иврита.
    - Показывайте цены в местной валюте.
    - Меняйте имена, даты и карты в интерфейсе под рынок, чтобы он выглядел своим.
  </Tab>
</Tabs>

## Видео предпросмотра

<Accordion title="Когда добавлять видео">
  Видео стоит перед скриншотами и запускается без звука. Лучше всего подходит:

  - **сложным приложениям**, смысл которых лучше показать в движении;
  - **играм** — почти всегда полезно, сразу показывайте игру;
  - **приложениям с особым взаимодействием**: жестами, анимацией и живыми функциями.

  **Правила:**
  - Захватите внимание за первые три секунды самой сильной функцией.
  - Держите длину 15–30 секунд; более длинные видео теряют зрителей.
  - Рассчитывайте на просмотр без звука: добавьте субтитры, не полагайтесь на речь.
  - Показывайте настоящее использование, а не рекламную анимацию.
  - Завершите ясным призывом.

  **Когда не нужно:**
  - простому инструменту, который целиком понятен по кадрам;
  - приложению, где главное — контент (новости, подкасты, книги), а не интерфейс.
</Accordion>

## Инструменты MCP

При подключении [сервера Appeeky MCP](https://docs.appeeky.com/mcp) навык получает:

| Инструмент | Что получает |
|------------|--------------|
| `get_app` | Ваши скриншоты, метаданные, оценку и место в категории |
| `get_competitor_screenshots` | Скриншоты ведущих конкурентов для сравнения |
| `get_category_screenshots` | Кадры категории для поиска общих приёмов и пробелов |

<Note>
  Без Appeeky навык попросит описать или вставить ваши скриншоты и примеры конкурентов, а затем применит ту же схему 10 кадров и форму задания дизайнеру.
</Note>
