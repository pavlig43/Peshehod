# Видео предпросмотра приложения

Помогите пользователю сделать до трёх роликов App Preview для iOS или один ролик для Google Play, чтобы повысить долю установок со страницы приложения на 5–25%.

## С чего начать

1. Найдите `app-marketing-context.md` и прочитайте о приложении, людях, для которых оно создано, и его главной пользе.
2. Спросите **App ID** и **платформы**: iOS, Android или обе.
3. Узнайте, есть ли **готовые записи экрана** или нужны новые.
4. Уточните **цель**: установка приложения на раннем шаге либо запуск пробного срока после знакомства с ним.
5. Узнайте, для **каких языков и стран** нужен ролик: лишь английский или другие рынки.

## Требования платформ (запомните)

### App Preview для iOS

| Параметр | Значение |
|---|---|
| Длина | **15–30 секунд**, не дольше 30 |
| Число | **До трёх на каждый язык и страну** |
| Показ | **Самозапуск без звука** в поиске и на странице приложения |
| Положение | Вертикальное или горизонтальное; должно совпадать со снимками экрана |
| Разрешение | Родное разрешение устройства; для вертикального видео не ниже 1080×1920 |
| Кодек | H.264, MP4 / MOV |
| Частота кадров | 30 кадров/с |
| Кадр-обложка | Первый кадр, видимый при паузе; выберите его осознанно |
| Звук | Необязателен; большинство смотрит без него. Если звук передаёт смысл, нужны субтитры |
| Содержимое | **Лишь запись приложения**: без рекламных заставок, логотипов и живых людей |

### Рекламное видео для Google Play

| Параметр | Значение |
|---|---|
| Источник | **Ссылка на YouTube**, не загрузка файла |
| Длина | **Желательно 30 секунд**, не дольше двух минут |
| Вид | Лучше горизонтальный: Play запускает видео сам |
| Звук | Допустим и полезен |
| Содержимое | Правила мягче: можно снимать людей, добавлять голос и рекламную заставку |
| Место | Над снимками экрана на странице приложения |

## Схема ролика на 30 секунд

Берите эту покадровую схему для обеих платформ, меняя её по их правилам:

| Время | Часть | Правило iOS | Правило Play |
|---|---|---|---|
| 0:00–0:02 | **Зацепка:** покажите итог, а не название приложения | Только кадры приложения | Можно добавить логотип или заставку, не дольше трёх секунд |
| 0:02–0:08 | **Задача:** наложенный текст называет боль пользователя | Текст поверх записи приложения | Можно перейти к съёмке повседневной жизни |
| 0:08–0:20 | **Главная функция:** покажите, как она работает | Настоящая запись экрана; ускорение 1,25–1,5× допустимо | То же |
| 0:20–0:26 | **Другие функции и доверие:** быстрые кадры с итогами, оценками и иными функциями | Всё должно быть видно внутри приложения | Можно показать снимки отзывов |
| 0:26–0:30 | **Итог и призыв к действию** | Покажите конечное состояние, без «Скачать сейчас»: Apple отклонит | «Получить бесплатно» допустимо |

**Выбор первого кадра для iOS:** он должен цеплять взгляд и не быть перегружен текстом. Кадр на 0:00 увидят 80% людей.

## Как выдать сценарий

Если просят сценарий, подготовьте:

```
ВИДЕО ПРИЛОЖЕНИЯ — <название> — вариант <A|B|C>
Длина: 30 с | Платформа: iOS / Android | Язык и страна: en-US

ПЕРВЫЙ КАДР: <описание кадра 0>

00:00–00:02  ЗАЦЕПКА
  Картинка: <что видно>
  Текст поверх: «<текст>»
  Звук: <если нужен>

00:02–00:08  ЗАДАЧА
  Картинка: ...
  Текст поверх: «...»

[продолжайте по частям]

ЗАМЕТКИ ДЛЯ СЪЁМКИ:
  - Записать на <модель устройства>, <версия iOS>
  - Состояние пробной учётной записи: <какие данные нужны>
  - Ускорить: <какие части>
  - Встроенные субтитры, если есть голос: да/нет
```

## Три разных ролика для iOS

Apple разрешает загрузить три App Preview. Не делайте три одинаковых: меняйте начальную зацепку.

| Вариант | Начало | Когда iOS покажет |
|---|---|---|
| **A — итог** | Начните с пользы: «Спите лучше за семь дней» | Первым по умолчанию |
| **B — показ** | Покажите работу функции и путь по интерфейсу | Вторым |
| **C — доказательство** | Покажите числа, итоги и отзывы внутри приложения | Третьим |

Порядок можно менять. Обычно первым ставьте итог, кроме категорий, где важнее показать сложную работу приложения.

## Проверка перед отправкой

- [ ] Запись сделана в родном разрешении устройства.
- [ ] Нет надписей «Скачать сейчас», «Доступно в App Store» и наложенного значка приложения: правило Apple 2.3.10.
- [ ] Нет рекламной заставки без записи приложения для Apple; в Play Store она допустима.
- [ ] Звук несёт смысл и снабжён субтитрами либо вовсе удалён.
- [ ] На первом кадре нет слова, набранного лишь наполовину.
- [ ] Проверен вид в **маленькой карточке поиска** и на **крупной странице приложения**.
- [ ] Каждый вариант загружен в своё место: добавляйте, а не заменяйте.
- [ ] Для приложения, выходящего в разные страны, сделаны варианты хотя бы для трёх главных рынков.

## Почему Apple часто отклоняет ролики

| Проблема | Что сделать |
|---|---|
| Видны живые люди или руки | Уберите их; оставьте лишь запись приложения |
| Рекламный логотип или заставка | Уберите первые 1–2 секунды |
| Призыв «Скачать» в конце | Замените кадром с итогом работы |
| Запись не совпадает с текущей версией приложения | После большой смены интерфейса запишите снова |
| Есть голос, но нет субтитров | Добавьте субтитры в видео или уберите голос |

## Перевод для разных рынков

- **Первый ряд**: английский, японский, немецкий, французский, испанский, китайский. Переведите наложенный текст и снимите экран заново с переведённым интерфейсом.
- **Второй ряд**: другие рынки с высоким доходом. Переведите наложенный текст, а кадры приложения можно оставить на английском, если само оно переведено не полностью.
- **Третий ряд**: один общий ролик без отдельного перевода.

Соотношение затрат и пользы: видео на языке страны обычно поднимает долю установок там на 8–15% по сравнению с общим английским роликом.

## Проверка разных вариантов

App Preview для iOS можно проверить через **Product Page Optimization (PPO)**; см. `ab-test-store-listing`. Держите опыт не меньше 14 дней и стремитесь к достоверности ≥95%. Главный показатель — **доля установок со страницы приложения**; второй — **доля досмотров видео**, которая помогает оценить начальную зацепку.
