# Приглашения друзей с наградами

Вы разбираетесь в росте через советы друзей. Помогите сделать программу, которая заметно добавит установок — в зрелом виде обычно 5–20% новых установок, — но не даст обманом получать награды и не сделает каждую установку убыточной.

## С чего начать

1. Найдите `app-marketing-context.md`.
2. Спросите, **зачем люди захотят звать друзей**: общая игра, совместная работа, общение, выгода или статус?
3. Узнайте **CAC** — цену установки через рекламу: это верхняя граница расходов на приглашение.
4. Узнайте **ARPU и LTV** нового платящего человека.
5. Спросите, **есть ли уже MMP и глубокие ссылки**: Branch, AppsFlyer OneLink или Adjust.
6. Уточните **аудиторию**: бывают ли в приложении естественные моменты поделиться?

Если LTV неизвестен, сперва примените `asc-metrics`. Без срока возврата затрат нельзя выбрать размер награды.

## Подходит ли программа приложению

| Сильный выбор | Слабый выбор |
|--------------|-------------|
| Польза растёт с числом людей: чат, соцсеть, игра вместе, торговая площадка | Инструмент для одного человека без повода делиться |
| Высокий LTV или много платящих людей | Бесплатное приложение с низким ARPU, где награда слишком дорога |
| Есть итог или материалы, которыми хочется хвастаться | Пользователи стесняются рассказывать о приложении |
| Люди возвращаются часто, лучше каждый день | Инструмент на один раз |
| Люди уже советуют приложение сами | Пока никто не делится им без просьбы |

Если выбор слабый, лучше предложить `creator-ugc-marketing` или `retention-optimization`.

## Как устроить награды

| Схема | Как работает | Для чего лучше |
|-------|--------------|----------------|
| **Обеим сторонам**, по $X зовущему и новому человеку | Самая частая и справедливая | Большинство массовых приложений |
| **Только зовущему** | Награду получает лишь тот, кто отправил ссылку | Когда человеку и так хочется поставить приложение |
| **Только новому человеку** | Новичок получает скидку, зовущий — ничего | Привлечение новых без цели широкого распространения через сеть |
| **По ступеням**, например «Позовите пятерых — год бесплатно» | Крупная награда за число приглашений | Очень активные пользователи, люди, которым важен статус |
| **Валюта или баллы приложения** | Обе стороны получают внутренние единицы, деньги не уходят из компании | Игры и приложения с покупками материалов |
| **Статус или внешний вид** | Знак, тема, аватар; почти бесплатно | Соцсети и сообщества |
| **Деньги** | Выплата человеку | Финансовые сервисы и торговые площадки; высокий риск обмана |

## Размер награды

Расчёт:

```
Предельная награда за приглашение на одну сторону ≤ (LTV × целевая доля прибыли) - другие затраты CAC
```

**Частые рабочие варианты:**
- Подписка: по месяцу бесплатно обеим сторонам; цена около $5–15.
- Торговая площадка: новичку $5–25 на счёт, зовущему $5–15.
- Игра: 50–500 единиц игровой валюты или по одному украшению.
- Финансовый сервис: $5–25 деньгами, но лишь после нужного действия новичка.

**Плохая схема:** награда выше CAC. Тогда пришедший по совету человек обходится дороже привлечённого рекламой.

## Коэффициент роста K

```
K = (число приглашений на человека) × (доля приглашённых, которые пришли)
```

| Значение K | Смысл |
|------------|-------|
| K < 0,15 | Приятное доп. число установок, но не главный путь роста |
| K = 0,15–0,5 | Заметный вклад, можно улучшать |
| K = 0,5–1,0 | Сильно усиливает рекламу и бесплатный рост |
| K > 1,0 | Настоящий рост сам по себе, встречается очень редко |

Разумная цель для большинства приложений — **K = 0,2–0,4**. Выше 0,5 выходит лишь при очень сильной пользе от сети людей.

## Список для внедрения

- [ ] **Место просьбы:** предлагайте звать друзей после полезного действия, не при установке; повторяйте на важных рубежах.
- [ ] **Поделиться одним нажатием:** родное меню отправки с личной ссылкой и готовым текстом.
- [ ] **Глубокая ссылка с отложенным открытием:** новичок нажал → поставил приложение → открыл экран «Добро пожаловать, друг <имя>!» с наградой.
- [ ] **Учёт награды:** обе стороны получают её сами, зовущий сразу видит результат.
- [ ] **Видимый ход:** экран «Вы позвали X друзей и получили Y».
- [ ] **Ступени:** полоса до следующей награды.
- [ ] **Разные тексты отправки:** проверьте варианты A/B.
- [ ] **Разные способы отправки:** iMessage, WhatsApp, копирование ссылки, X, история IG, почта.
- [ ] **И код, и ссылка:** некоторые люди называют код голосом.
- [ ] **Журнал выдачи наград:** для помощи пользователям и поиска обмана.

## Защита от обмана

Приглашения с наградами привлекают злоупотребления:

| Способ обмана | Защита |
|--------------|--------|
| Пригласить самого себя с другого устройства | Отпечаток устройства, IDFV или Android ID, блок по IP |
| Регистрировать людей ради награды и сразу уходить | Выдавать награду лишь после покупки или нужного срока пользования |
| Регистрация ботами | До выдачи проверить ATT, почту или телефон |
| Копить много наград по нескольким акциям | Предел на зовущего, например 50 приглашений или сумму $X |
| Рассылать ссылку всем подряд | Оценивать долю принятых приглашений, ограничивать нарушителей |
| Особый случай семейного доступа | Найти и заблокировать; Apple даёт признак в чеках |

Для денежных наград в финансовом сервисе заложите потерю 5–15% на обман. Сделайте общий выключатель программы.

## Средства

| Задача | Средство |
|--------|----------|
| Глубокие ссылки и учёт после установки | Branch, AppsFlyer OneLink, Adjust, Singular |
| Готовая система приглашений | Branch Referrals, Tapfiliate, Friendbuy |
| Своя система с широкой настройкой | Глубокие ссылки MMP и свой сервер |

Для большинства команд **глубокие ссылки MMP и свой сервер** подходят, когда плата за готовую систему превышает $1000 в месяц.

## Частые ошибки

- Запуск без отложенного перехода по глубокой ссылке: установка после неё теряет связь с приглашением.
- Награда больше CAC: за пришедшего по совету платят больше, чем приносит реклама.
- Выдача награды до проверки, что новичок настоящий: лёгкий путь для обмана.
- Один неизменный текст для отправки: люди не хотят его править, и ссылки распространяются хуже.
- Просьба позвать друзей лишь раз: показ при установке даёт около 2% участия, три и больше показов после подходящих действий — 15–25%.
- Считать лишь отправленные приглашения: без числа пришедших и выполнивших нужное действие эта метрика мало значит.
