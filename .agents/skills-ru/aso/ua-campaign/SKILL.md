# Кампании по привлечению людей

Вы разбираетесь в рекламе мобильных приложений на главных площадках. Помогите запустить и улучшить платные кампании, которые приносят установки с выгодой.

## С чего начать

1. Найдите `app-marketing-context.md` и прочитайте сведения.
2. Спросите **месячный бюджет на привлечение**: он влияет на выбор площадок.
3. Спросите **целевую цену установки (CPI)** или **возврат трат на рекламу (ROAS)**.
4. Узнайте нынешний **LTV** — доход за всё время жизни одного пользователя.
5. Уточните **аудиторию**: возраст и другие признаки, интересы, поведение.
6. Уточните **страны**.
7. Уточните **категорию приложения**: она влияет на выбор площадок.

## Apple Search Ads — главная площадка

### Почему начать здесь

- Человек уже ищет приложение, поэтому намерение высокое.
- Доля установок после нажатия — 30–50%.
- Реклама напрямую связана с App Store.
- Подходит для любого бюджета.

### Устройство кампаний

```
Учётная запись
├── Кампания бренда (точное совпадение)
│   ├── [название вашего приложения]
│   └── [частые опечатки]
├── Кампания категории (широкое и точное совпадение)
│   ├── [слова категории]
│   └── [слова о функциях]
├── Кампания по соперникам (точное совпадение)
│   ├── [имя соперника 1]
│   └── [имя соперника 2]
└── Кампания поиска новых слов (Search Match)
    └── Подбор слов системой
```

### Ставки

| Вид кампании | Как ставить | Целевой CPA |
|--------------|-------------|-------------|
| Бренд | Низкие ставки, много запросов | Менее $0,50 |
| Категория | Средние ставки | $1–3 |
| Соперники | Более высокие ставки, меньше запросов | $2–5 |
| Поиск новых слов | Низкие ставки, широкий охват | $1–3 |

### Что проверять при улучшении

- [ ] Добавить минус-слова из кампании поиска новых слов, чтобы не тратить деньги зря.
- [ ] Перенести удачные найденные слова в кампании с точным совпадением.
- [ ] Остановить слова с CPA выше цели более чем вдвое.
- [ ] Поднять ставки по словам с CPA ниже цели.
- [ ] Проверить особые страницы продукта для разных целей поиска.
- [ ] Каждую неделю разбирать слова, найденные через Search Match.
- [ ] Менять ставки по дням недели и времени суток.

## Кампании Meta (Facebook/Instagram)

### Устройство кампании

```
Кампания: установки приложения
├── Набор 1: похожие на платящих пользователей (1%)
│   ├── Объявление: видео с показом функции (15 с)
│   ├── Объявление: карусель функций
│   └── Объявление: статичная картинка с пользой
├── Набор 2: выбор по интересам
│   ├── Объявление: видео «проблема и решение»
│   └── Объявление: отзыв в стиле пользовательского видео
└── Набор 3: широкий выбор — подбор Meta
    ├── Объявление: лучший вариант выше
    └── Объявление: новая картинка для проверки
```

### Правила рекламных материалов

**Видео — часто работает лучше всего:**
- Зацепите в первые три секунды.
- Покажите приложение в деле.
- Подходящая длина — 15–30 секунд.
- Видео понятно без звука благодаря субтитрам.
- Завершите ясным призывом и знаком App Store.

**Неподвижные объявления:**
- Заметный заголовок о главной пользе.
- Снимок приложения или макет.
- Доводы для доверия: оценка, число пользователей.
- Ясная кнопка «Скачать бесплатно».

### Как находить аудиторию

1. **Основа:** загрузите адреса платящих людей и создайте похожую аудиторию.
2. **Рост:** расширяйте сходство с 1% до 3%, затем 5% по мере роста бюджета.
3. **Группы:** добавьте выбор по интересам для отдельных людей.
4. **Широкий охват:** дайте алгоритму Meta самому искать людей, когда данных достаточно.

## Google UAC — общие кампании приложений

### Настройка

- Дайте четыре варианта текста, двадцать картинок и пять видео.
- Задайте целевой CPI или CPA.
- Google сам соберёт и проверит сочетания объявлений.
- Показы идут в поиске, на сайтах, YouTube и в Play Store.

### Улучшение

- Вложите силы в материалы: подбор людей делает Google.
- Проверьте разные обещания пользы в тексте.
- Дайте разные картинки и ролики.
- Ставьте достижимые цели CPA: начните выше и снижайте постепенно.

## Главные числа и правки

### Путь человека

```
Показы → Нажатия → Установки → Первые полезные действия → Покупки
  CTR       CVR        CPI                 CPA                 ROAS
```

| Показатель | Формула | Цель |
|------------|---------|------|
| CTR | Нажатия / Показы | Более 5% для ASA, более 1% для соцсетей |
| CVR | Установки / Нажатия | Более 30% для ASA, более 10% для соцсетей |
| CPI | Траты / Установки | Меньше LTV / 3 |
| CPA | Траты / Покупки | Меньше LTV |
| ROAS | Доход / Траты | Более 1,0 — окупается, более 2,0 — хорошо |
| ROAS за семь дней | Доход за первые семь дней / Траты | Помогает предсказать ROAS за долгий срок |

### Как часто проверять

| Частота | Действие |
|---------|----------|
| Каждый день | Проверять ход трат и останавливать слишком быстрые |
| Раз в неделю | Смотреть CPI/CPA по словам и наборам объявлений, менять ставки |
| Раз в две недели | Обновлять материалы: через 2–3 недели люди устают от одних объявлений |
| Раз в месяц | Сравнивать площадки, переводить деньги туда, где итог лучше |
| Раз в квартал | Проверять общий план и пробовать новые площадки |

### План привлечения

```
Бюджет в месяц: $[X]
Целевой CPI: $[X]
Цель по установкам за месяц: [N]

Бюджет по площадкам:
- Apple Search Ads: [X]% ($[X])
- Meta: [X]% ($[X])
- Google UAC: [X]% ($[X])
- Пробы: [X]% ($[X])

Неделя 1: [настройка]
Неделя 2: [запуск]
Недели 3–4: [правки по первым данным]
```

### Задания по площадкам

Для каждой площадки укажите:
- устройство кампании;
- способ выбора аудитории;
- нужные рекламные материалы;
- бюджет и советы по ставкам;
- целевые показатели.
