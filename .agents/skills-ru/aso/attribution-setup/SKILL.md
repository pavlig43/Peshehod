# Учёт источников установки

Вы разбираетесь в том, как связать установку и доход с рекламой, которая их привела. Настройте или исправьте сбор данных с учётом защиты частной жизни на iOS.

## С чего начать

1. Найдите `app-marketing-context.md`.
2. Уточните **платформы**: iOS, Android или обе.
3. Спросите, **есть ли MMP** — AppsFlyer, Adjust, Singular, Branch или Kochava. Если есть, какой именно.
4. Уточните, **где идёт или планируется реклама**: ASA, Meta, TikTok, Google UAC и другое.
5. Спросите, **что не работает или чего хотят достичь**: новая настройка, разница чисел, лучшие значения конверсии, переход на AdAttributionKit и так далее.

## Как на деле устроен учёт на iOS с 2024 года

| Способ | Состояние | Для чего |
|---|---|---|
| **IDFA** при согласии через ATT | Доступен, но согласны около 25% людей | Точный учёт там, где есть согласие |
| **SKAdNetwork (SKAN 4.0)** | Учёт Apple с защитой частной жизни | Основа для рекламных сетей |
| **AdAttributionKit (AAK)** | iOS 17.4+, развитие SKAN от Apple | Применять рядом со SKAN; часть сетей требует |
| **Вероятностный учёт MMP** | Apple запрещает отпечатки устройств; допустимы лишь узкие случаи | Ограниченно; проверьте условия MMP |
| **Учёт Apple Search Ads** | Подробные кампании и слова только для ASA | Всегда для ASA |

**Обычный набор в 2025 году:** встроенный учёт ASA, SKAN 4, AdAttributionKit, MMP для общего сбора и API Apple Search Ads для подробностей ASA.

## Основа SKAdNetwork 4.0

| Термин | Смысл |
|---|---|
| **Postback** | Сообщение, которым Apple подтверждает установку рекламной сети |
| **Значение конверсии (CV)** | Число из 6 бит: точное 0–63, либо из 2 бит: грубое «низкое/среднее/высокое»; оно кодирует действие человека |
| **Окно обратного сообщения** | Три окна после установки: 0–2, 3–7 и 8–35 дней |
| **Порог частной жизни** | При малом числе установок значение становится грубым или пустым |
| **Иерархический ID источника** | Четыре цифры кодируют кампанию, объявление и картинку |
| **Переход с сайта в приложение** | SKAN теперь учитывает установки по пути Safari → App Store |

Главное решение — **схема значений конверсии**.

## Как устроить значения конверсии

Плохая схема CV не даст улучшать рекламу. Хорошая схема:

1. **Связана с LTV:** кодирует действия, которые предсказывают оплату, а не числа ради отчёта.
2. **Даёт ранний сигнал:** больше всего сведений в первом окне, 0–2 дня.
3. **По возможности растёт:** больший CV означает более ценного человека.

**Образец для подписки — первое окно, точное значение из 6 бит:**

| CV | Действие |
|---|---|
| 0 | Только установка |
| 1–5 | Закончены первые шаги |
| 6–15 | Выполнено первое полезное действие, например первый сеанс ≥X |
| 16–30 | Начат пробный срок |
| 31–45 | Экран оплаты показан N раз — интерес к покупке |
| 46–63 | Куплена подписка |

Второе окно, 3–7-й дни: переход с пробы на оплату и группы ARPU.
Третье окно, 8–35-й дни: возврат на 7-й и 14-й дни и признак продления подписки.

Для приложений без подписки замените события пробы и подписки группами дохода: $0, $1–5, $5–20, $20–50 и от $50.

## Список настройки по MMP

### AppsFlyer

- [ ] SDK подключён; `AppsFlyerLib.shared().start()` вызывается в `applicationDidFinishLaunching`.
- [ ] App ID и ключ разработчика заданы в панели.
- [ ] Для SKAN выбран режим, лучше Conversion Studio.
- [ ] AdAttributionKit включён для приложений iOS 17.4+.
- [ ] OneLink настроен для глубоких ссылок.
- [ ] События покупки, подписки и начала пробы отправляются через `logEvent`.
- [ ] Окно ATT показывается до обращения SDK к IDFA.
- [ ] Подключены рекламные сети: Meta, TikTok, Google и другие.

### Adjust

- [ ] SDK и токен переданы в `Adjust.appDidLaunch(...)`.
- [ ] Значения конверсии заданы в панели или коде SDK.
- [ ] Вместе включены AdAttributionKit и SKAN.
- [ ] Учитываются подписки; для точности советуются App Store Server Notifications.
- [ ] Глубокие ссылки открываются через `AdjustDeeplink`.

### Singular

- [ ] SDK запущен с ключом API.
- [ ] Настроены SKAN и AdAttributionKit.
- [ ] Для схемы конверсии выбран Predicted LTV или Custom Events.
- [ ] Подключён сбор затрат из ASA, Meta, TikTok и Google.

### Branch — прежде всего для глубоких ссылок

- [ ] Проверены домены Universal Links и App Links.
- [ ] Проверена отложенная ссылка: установка и первый запуск ведут на нужный экран.
- [ ] При работе Branch как MMP включены Branch Discounts или People-Based Attribution.

## Учёт на Android

Он проще, чем на iOS:

| Способ | Для чего |
|---|---|
| **Google Play Install Referrer API** | Точный источник установки; подключайте всегда |
| **Google Ads Attribution** | Встроенный учёт для UAC |
| **MMP SDK** | Как на iOS, для Meta, TikTok и других |

Подключайте Install Referrer API и при наличии MMP: это главный источник достоверных данных.

## Виды глубоких ссылок

| Вид | Когда брать |
|---|---|
| **Universal Links на iOS / App Links на Android** | Открыть установленное приложение с сайта или письма, иначе открыть сайт |
| **Отложенная глубокая ссылка** | После установки по рекламе и первого запуска открыть точный экран |
| **Своя схема URL** (`myapp://`) | Лишь для переходов внутри приложения, не для рекламы |

Проверяйте сочетания: установлено ли приложение × источник × ОС × версия ОС. Частая ошибка: на Android отложенная ссылка работает, а на iOS открывается главная App Store, потому что домен Universal Links не проверен.

## Поиск неполадок

| Признак | Возможная причина |
|---|---|
| MMP видит установки, а рекламная сеть — нет | Время postback или слишком мало установок для порога приватности |
| Учёт ASA видит больше установок, чем MMP | В MMP нет связи с `iAd Framework`; перейдите на AdServices framework для iOS 14.3+ |
| Все CV равны нулю или пусты | Малый поток для порога приватности либо схема не внедрена в код |
| Install Referrer пуст на Android | API не вызван в первые 60 секунд после первого запуска |
| Отложенная ссылка теряет параметры | Приложение не принимает их при запуске из закрытого состояния |
| Доход в MMP не равен RevenueCat или ASC | Перевод валют, возвраты и семейный доступ; разница 5–10% возможна |

## Частые ошибки

- Показывать ATT слишком рано: меньше людей согласятся; лучше после первого полезного действия.
- Кодировать в CV лишь числа сеансов вместо признаков будущего дохода.
- Не проверить порог приватности: у маленькой кампании CV будут пустыми.
- Брать ссылки со схемой URL в рекламе: они не сработают без установленного приложения.
- Забыть AdServices framework для ASA: число установок ASA может тихо занизиться на 30–60%.
- Смешать настройку CV в SDK и панели: выберите один путь.
