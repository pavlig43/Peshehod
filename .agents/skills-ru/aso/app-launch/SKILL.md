# План выхода приложения

Вы разбираетесь в выпуске мобильных приложений — от небольших личных проектов до лидеров чартов. Составьте полный план, чтобы приложение заметили в первый день и интерес не угас после него.

## С чего начать

1. Найдите `app-marketing-context.md` и прочитайте сведения о приложении.
2. Уточните: **новое приложение или крупное обновление?**
3. Спросите **дату выхода** и можно ли её менять.
4. Уточните **бюджет**: только бесплатные способы или есть деньги на рекламу?
5. Есть ли **готовая аудитория**: список почтовых адресов, подписчики, пользователи старой версии?
6. Какие **страны** выбраны: выход сразу везде или по шагам?

## Сроки подготовки

### За восемь недель

**Основа ASO:**
- [ ] Найти слова, по которым приложение будут искать, с помощью `keyword-research`.
- [ ] Составить название, подзаголовок и поле слов через `metadata-optimization`.
- [ ] Изучить соперников через `competitor-analysis`.
- [ ] Сделать снимки экрана с помощью `screenshot-optimization`.
- [ ] Сделать видео предпросмотра на 15–30 секунд.
- [ ] Написать убедительное описание с сильными первыми тремя строками.
- [ ] Нарисовать особый, узнаваемый значок.

**Страница до выхода — для нового приложения:**
- [ ] Настроить страницу предзаказа в App Store.
- [ ] Включить сообщения о начале загрузки по предзаказу.
- [ ] Раздать ссылку на предзаказ, чтобы собрать первых людей.

**Пресса и сообщества:**
- [ ] Собрать набор для прессы: снимки, значок, описание, историю автора.
- [ ] Найти 20–30 подходящих журналистов, блогеров и авторов YouTube.
- [ ] Написать личные письма с предложением рассказать о приложении.
- [ ] Найти сообщества по теме: Reddit, Discord, форумы, Twitter/X.

### За четыре недели

**Пробная версия и отзывы:**
- [ ] Дать пробную версию TestFlight 50–200 людям.
- [ ] Собрать замечания и исправить серьёзные ошибки.
- [ ] Попросить участников пробной версии быть готовыми написать отзыв в день выхода.
- [ ] Подготовить ответы на частые вопросы и справку.

**Материалы:**
- [ ] Написать статью о выходе приложения.
- [ ] Подготовить записи для соцсетей: больше десяти на неделю выхода.
- [ ] Сделать ролик с показом работы для соцсетей.
- [ ] Подготовить страницу Product Hunt, если это подходит продукту.

**Техника:**
- [ ] Настроить аналитику через `app-analytics`.
- [ ] Добавить просьбу оценить приложение после удачного действия.
- [ ] Настроить учёт сбоев.
- [ ] Проверить покупки внутри приложения и подписки.

### За неделю

**Последние шаги:**
- [ ] Отправить приложение на проверку, оставив запас два-три дня.
- [ ] Назначить конец запрета на публикации в прессе на день выхода.
- [ ] Подготовить записи в соцсетях на день выхода.
- [ ] Напомнить участникам пробной версии, когда писать отзывы.
- [ ] Настроить выпуск по этапам либо сразу в App Store Connect.
- [ ] Подготовить рекламу Apple Search Ads через `ua-campaign`.

### В день выхода

**Утром:**
- [ ] Выпустить приложение или проверить, что выход по этапам начался.
- [ ] Разослать письма в прессу после снятия запрета.
- [ ] Написать в личных и рабочих соцсетях.
- [ ] Опубликовать страницу Product Hunt, если она нужна.
- [ ] Написать в подходящих сообществах: Reddit, Discord, на форумах.
- [ ] Отправить письмо своему списку подписчиков.

**В течение дня:**
- [ ] Следить за загрузками в App Store Connect.
- [ ] Отвечать на каждый отзыв с помощью `review-management`.
- [ ] Отвечать тем, кто упомянул приложение в соцсетях.
- [ ] Следить за сбоями.
- [ ] Делиться вехами: «Мы на месте № X в [категории]!».

**Вечером:**
- [ ] Публично поблагодарить первых пользователей.
- [ ] Поделиться числами первого дня, если они впечатляют.
- [ ] Намечать материалы на завтра.

### Первая неделя после выхода

- [ ] Писать в соцсетях каждый день.
- [ ] Отвечать на все отзывы.
- [ ] Следить за местами по поисковым словам: попало ли приложение в указатель поиска?
- [ ] Менять ставки Apple Search Ads по итогам рекламы.
- [ ] Ещё раз написать в прессу тем, кто не ответил.
- [ ] Предложить приложение редакции App Store для подборок через `app-store-featured`.
- [ ] Разобрать показатели первой недели и подстроить план.

### Первый месяц после выхода

- [ ] Провести полный `aso-audit` по настоящим данным.
- [ ] Исправить данные страницы по тому, как сработали поисковые слова.
- [ ] Проверить разные снимки экрана через `ab-test-store-listing`.
- [ ] Намечать первое крупное обновление по отзывам людей.
- [ ] Оценить возврат трат на платное привлечение.
- [ ] Настроить постоянное слежение за поисковыми словами.

## Как усилить выход

### Бесплатные пути

1. **Product Hunt** — хорошо для программ для работы, дизайна и разработки.
2. **Hacker News (Show HN)** — для новых технических идей и необычных приложений.
3. **Reddit** — найдите 3–5 подходящих сообществ и участвуйте в беседах ещё до продвижения.
4. **Twitter/X** — рассказывайте о ходе разработки и объявите о выходе.
5. **LinkedIn** — если приложение для компаний или работы.
6. **YouTube** — показ работы и история создания.
7. **Сайты с обзорами приложений** — AppAdvice, MacStories, 9to5Mac и другие.

### Платные пути

1. **Apple Search Ads** — самые заинтересованные люди; начните здесь.
2. **Meta (Facebook/Instagram)** — хорошо для массовых приложений.
3. **TikTok** — для молодой аудитории.
4. **Google Ads (UAC)** — широкий охват.
5. **Работа с авторами** — небольшие блогеры с 10–100 тысячами подписчиков часто дают лучший возврат затрат.

## Вид ответа

### План выхода

Дайте полный список дел с датами, по которому можно идти. Включите:
1. Календарь с точными датами по сроку выхода.
2. Задачи каждого этапа по важности.
3. Способы продвижения с точными действиями.
4. Распределение бюджета, если есть платные пути.
5. Показатели успеха и цели на первую неделю, первый и третий месяцы.

## Связанные навыки

- `aso-audit` — проверка ASO после выхода.
- `keyword-research` — слова для поиска до выхода.
- `metadata-optimization` — данные страницы на день выхода.
- `screenshot-optimization` — снимки экрана к выходу.
- `ua-campaign` — платное привлечение в день выхода.
- `app-store-featured` — путь в редакционные подборки.
- `review-management` — ответы на отзывы в день выхода.
