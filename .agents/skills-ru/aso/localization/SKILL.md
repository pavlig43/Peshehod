# Перевод страницы App Store для других рынков

Вы разбираетесь в выходе приложений на другие рынки. Помогите пользователю расширить охват за счёт хорошего перевода и подстройки страницы App Store под каждую страну.

## С чего начать

1. Найдите `app-marketing-context.md` и прочитайте о нынешних рынках и языках.
2. Спросите **App ID**, чтобы увидеть готовые переводы.
3. Уточните, **переведено ли само приложение** — интерфейс и содержимое — или только страница магазина.
4. Спросите, **какие страны** пользователь рассматривает.
5. Уточните **бюджет**: работа с профессиональным переводчиком или помощь ИИ?

### Как выбрать

Оцените каждую страну:

| Признак | Вес | Как оценить |
|---------|-----|-------------|
| Размер рынка | 30% | Сколько в стране людей с iPhone |
| Соперничество | 25% | Сколько соперников уже перевели страницы |
| Трудозатраты | 20% | Сложность перевода и разница культур |
| Возможный доход | 15% | Доход на пользователя в стране |
| Близость цели | 10% | Решает ли приложение местную задачу? |

## Список для перевода

### Данные страницы

Для каждой целевой страны:

- [ ] **Название** (30 знаков): с ключевыми словами для местного поиска.
- [ ] **Подзаголовок** (30 знаков): с местными поисковыми словами.
- [ ] **Поле ключевых слов** (100 знаков): новый поиск слов для каждой страны.
- [ ] **Описание** (4000 знаков): перевод с учётом местной культуры.
- [ ] **Рекламный текст** (170 знаков): под местные события и сезоны.
- [ ] **Что нового:** перевод для каждого обновления.
- [ ] **Снимки экрана:** перевод надписей и подходящие местные образы.
- [ ] **Видео App Preview:** субтитры или отдельный переведённый ролик.

### Главное: слова для поиска нельзя просто перевести

**Самая частая ошибка** — прямой перевод английских ключевых слов.

Вместо этого:
1. Запустите `keyword-research` отдельно для каждой страны.
2. Узнайте, какими словами местные жители ищут приложение: они могут иначе называть задачу и иметь другую цель.
3. Проверьте местные подсказки поиска.
4. Посмотрите, какие слова берут местные соперники для своих страниц.

**Пример:**
- Английский запрос: «budget tracker».
- Немецкий: «Haushaltsbuch» — домашняя книга расходов, а не «Budget Tracker».
- Японский: «家計簿» — семейная книга учёта, другой образ задачи.
- Испанский: «control de gastos» — учёт трат, иной акцент.

### Учёт местной культуры

| Элемент | Что проверить |
|---------|---------------|
| Снимки экрана | Знаки валют, запись дат и чисел |
| Цвета | Местный смысл цвета: красный — удача в Китае, опасность на Западе |
| Картинки | Разные люди и образы, уместные в стране |
| Тон | Уместно ли говорить строго или свободно |
| Функции | Выделены ли те, что нужны местным людям |
| Доверие | Местная пресса и число пользователей из страны, если есть |
| Цены | Местные ожидания и разница покупательной силы |

## Ход работы

### Этап 1. Поиск данных по каждой стране

1. Изучите десять лучших приложений категории на местном рынке.
2. Найдите поисковые слова, начиная с местных исходных слов.
3. Определите местных соперников и их место на рынке.
4. Изучите нынешние тренды местного App Store.

### Этап 2. Перевод и подстройка

**Для названия, подзаголовка и ключевых слов:**
- Привлеките носителей языка со знанием ASO, а не только переводчиков.
- Дайте контекст: «Это название в App Store; в нём должно быть слово [запрос]».
- Сверьте с данными поиска: вошли ли в перевод слова, которые люди ищут часто?

**Для описания:**
- Нужен хороший перевод с учётом местной культуры.
- Не переводите слово в слово: подстройте примеры, отсылки и юмор.
- Сохраните ход убеждения в тексте.

**Для снимков экрана:**
- Переведите текст поверх снимков.
- Если само приложение переведено, покажите местный язык в интерфейсе.
- Учтите вкусы людей в этой стране.

### Этап 3. Выход и слежение за итогом

1. Отправьте переведённые данные страницы.
2. Каждую неделю смотрите места по запросам в каждой стране.
3. Следите за долей установок по странам.
4. Меняйте страницу по итоговым данным.

## Вид ответа

### План по странам

Для каждого советуемого рынка:

```
## [Страна] — [язык]

Приоритет: [высокий/средний/низкий]
Трудозатраты: [часы/дни]
Ожидаемый итог: [оценка прироста загрузок]

Ключевые слова (лучшие десять):
| Запрос | Частота | Сложность | Близкий английский запрос |
|--------|---------|-----------|---------------------------|

Данные страницы:
- Название: [местный текст] ([X]/30 знаков)
- Подзаголовок: [местный текст] ([X]/30 знаков)
- Ключевые слова: [местный список] ([X]/100 знаков)

Местные особенности:
- [что нужно подстроить]
```
