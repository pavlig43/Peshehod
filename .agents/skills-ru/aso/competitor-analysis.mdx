Навык анализа конкурентов показывает, что делают ведущие соперники в App Store и какие возможности упускают. Вы увидите слова, по которым они ранжируются, а вы нет; разбор их скриншотов и других материалов; карту позиций на рынке; список шагов по важности, которые помогут выйти вперёд.

## Что нужно для начала

- **ID вашего приложения** — число Apple или имя пакета Google Play.
- **ID конкурентов** — до 3–5 приложений. Если не знаете кого выбрать, навык поможет найти их.
- **Целевая страна** — по умолчанию США.
- **Цель анализа** — пробелы в ключевых словах, визуальные материалы, позиционирование или полный разбор.

<Note>
  Если в проекте есть `app-marketing-context.md`, навык сначала прочтёт известных конкурентов и контекст стратегии. Повторно вводить уже записанные сведения не нужно.
</Note>

## Как вызвать навык

```text
/competitor-analysis
```

Или прямо опишите, что хотите узнать:

```text
«Сравни моё приложение (id: 493145008) с Calm (id: 571800810)»
```

```text
«Где я отстаю по ключевым словам и материалам?»
```

```text
«По каким словам виден мой главный конкурент, а меня нет?»
```

## Как найти нужных конкурентов

Если вы не знаете, кого изучать, навык найдёт их четырьмя способами:

<CardGroup cols={2}>
  <Card title="Рейтинг категории" icon="chart-bar">
    Лучшие приложения вашей категории — с ними вас сравнивает большинство пользователей.
  </Card>
  <Card title="Общие ключевые слова" icon="tags">
    Приложения, видимые по тем же запросам. Это ваши соперники в поиске, даже если категория немного другая.
  </Card>
  <Card title="Похожие приложения" icon="layer-group">
    Приложения из блока «Вам также может понравиться» на вашей странице. Apple показывает их по схожему поведению пользователей.
  </Card>
  <Card title="Замены в глазах пользователей" icon="people-group">
    Чем бы люди заменили ваше приложение, если бы оно исчезло? Спросите их или изучите упоминания замен в отзывах.
  </Card>
</CardGroup>

Хороший набор: **2 прямых конкурента** вашего размера, **1–2 более крупных ориентира** и **1 быстро растущий новичок**, способный занять ваше место.

## Что входит в анализ

<Tabs>
  <Tab title="Пробелы ключевых слов">
    Самая практичная часть. Навык сравнивает позиции ваших слов с каждым конкурентом и выдаёт три списка:

    **Слова, по которым видны конкуренты, а вы нет**, по убыванию объёма:

    | Ключевое слово | Объём | Сложность | Конкурент 1 | Конкурент 2 | Вы | Приоритет |
    |----------------|-------|------------|:-----------:|:-----------:|:--:|-----------|
    | sleep sounds | 88 | 72 | 3 | 7 | — | Высокий |
    | white noise app | 74 | 61 | 5 | 12 | — | Высокий |
    | bedtime stories | 68 | 55 | 4 | — | — | Средний |

    **Слова, по которым конкуренты выше вас** — возможность защитить или поднять свою позицию, отсортированная по разрыву и усилиям.

    **Ваши уникальные слова** — запросы, по которым вы видны, а конкуренты нет. Сохраняйте это преимущество, удерживая важные слова в названии и подзаголовке.
  </Tab>

  <Tab title="Разбор визуальных материалов">
    Системный разбор того, как конкуренты показывают приложение и что можно сделать лучше.

    **Скриншоты:** сколько из 10 мест занято; чем цепляет первый скриншот; есть ли текст поверх картинки и говорит ли он о пользе; какие функции показаны первыми; стиль (светлый/тёмный, рамки устройств, жизненные сцены); ориентация.

    **Видео предпросмотра:** есть ли оно; что происходит за первые три секунды; длина; понятен ли смысл без звука.

    **Иконка:** цвета, стиль и заметность среди результатов поиска.

    <Tip>
      Особо изучите первый скриншот главного конкурента. Крупные приложения часто проверяют его A/B-тестами. Если там долго держится один приём, есть шанс, что он выигрывает.
    </Tip>
  </Tab>

  <Tab title="Оценки и отзывы">
    Сравнение средних оценок, числа отзывов, свежей динамики и того, что пользователи любят и не любят у конкурентов.

    | Метрика | Ваше приложение | Конкурент 1 | Конкурент 2 | Конкурент 3 |
    |---------|:---------------:|:-----------:|:-----------:|:-----------:|
    | Оценка | 4.3 | 4.8 | 4.6 | 4.1 |
    | Всего отзывов | 12 тыс. | 890 тыс. | 340 тыс. | 28 тыс. |
    | За 30 дней | → | ↑ | → | ↓ |
    | Разработчик отвечает? | Нет | Да | Да | Нет |

    Ценнее самих оценок — **главные жалобы** в отзывах конкурентов. Каждая показывает пробел в функциях. Если тысячи людей ставят Calm две звезды из-за отсутствия работы без сети, а ваше приложение работает офлайн, расскажите об этом на скриншотах и в описании.
  </Tab>

  <Tab title="Сигналы роста">
    Как конкуренты растут или не растут и какие приёмы применяют:

    | Сигнал | Ваше приложение | Конкурент 1 | Конкурент 2 | Конкурент 3 |
    |--------|-----------------|-------------|-------------|-------------|
    | Место в категории | | | | |
    | Загрузки в месяц (оценка) | | | | |
    | Доход в месяц (оценка) | | | | |
    | Частота обновлений | | | | |
    | События In-App Events? | | | | |
    | Custom Product Pages? | | | | |
    | Есть Search Ads? | | | | |

    Если конкурент применяет In-App Events, а вы нет, он получает места во вкладке «Сегодня» и поиске, которые вы ему оставляете.
  </Tab>
</Tabs>

## Как выглядит результат

<Steps>
  <Step title="Краткий вывод">
    Два–три абзаца о рынке: кто ведёт и почему, где вы стоите, какие две–три возможности сейчас важнее всего.
  </Step>

  <Step title="Карта позиций">
    Визуальная карта вас и конкурентов по двум осям — обычно видимость в поиске и оценки:

    ```text
                       ВЫСОКАЯ ВИДИМОСТЬ
                              │
                Конк. 1 ●     │     ● Конк. 2
                              │
       НИЗКИЕ ────────────────┼──────────────── ВЫСОКИЕ
       ОЦЕНКИ                │                 ОЦЕНКИ
                              │
                       Вы ●  │
                              │
                       НИЗКАЯ ВИДИМОСТЬ
    ```

    Цель — сместиться в правый верхний угол. Карта показывает разрыв и соперников на пути.
  </Step>

  <Step title="Главные возможности">
    Пять конкретных шагов по скорости получения результата:

    1. **Быстрая правка** — то, что можно выпустить на этой неделе, например добавить частый запрос в подзаголовок.
    2. **Пробел в словах** — точные запросы с лучшим соотношением объёма и сложности, по которым конкуренты видны, а вы нет.
    3. **Сильные материалы** — правка скриншота или видео по результатам разбора.
    4. **Пробел в функциях** — то, на что жалуются у конкурентов и что у вас уже есть или можно добавить.
    5. **Пробел на рынке** — неохваченные аудитория, страна или сценарий.
  </Step>

  <Step title="Угрозы для слежения">
    Действия конкурентов на ближайшие 30–90 дней: расширение слов, быстрый рост новичка или тренд, способный изменить поиск в вашей категории.
  </Step>
</Steps>
