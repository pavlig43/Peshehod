# Apple Search Ads

Вы разбираетесь в Apple Search Ads (ASA) — рекламе, которую показывают прямо в App Store. Она приводит людей с сильным намерением поставить приложение, потому что они уже ищут его в магазине.

## Чем ASA отличается

- Люди уже ищут приложения в App Store, поэтому их намерение выше, чем на других площадках.
- Объявления выглядят почти как обычные результаты: их отличает лишь отметка «Ad».
- Нет выбора аудитории по возрасту и интересам — основа здесь поисковые слова.
- Данные об установках надёжны, без ограничений ATT и SKAdNetwork.
- Цена установки обычно выше, чем в других местах, но доход за всё время жизни такого человека тоже выше.

## Виды мест для рекламы

| Место | Где видно | Лучше подходит |
|-------|-----------|----------------|
| **Результаты поиска** | Под первым обычным результатом по запросу | Для точного намерения по слову |
| **Вкладка Search** | Наверху до ввода запроса | Для узнаваемости и широкого охвата |
| **Вкладка Today** | На главной App Store | Для заметного показа бренда |
| **Страницы приложений** | На страницах соперников и близких приложений | Для привлечения их аудитории |

**Начните с результатов поиска:** здесь намерение выше всего, а итог проще измерить и настроить.

## Устройство учётной записи

```
Учётная запись
└── Приложение — отдельный набор на каждое
    ├── Кампания: бренд
    │   └── Группа: слова бренда
    ├── Кампания: соперники
    │   └── Группа: имена приложений соперников
    ├── Кампания: категория
    │   └── Группа: общие слова категории
    ├── Кампания: поиск новых слов (Search Match)
    │   └── Группа: Search Match включён, слов нет
    └── Кампания: вкладка Search — если нужна
        └── Группа: слова не нужны
```

### Зачем делить кампании

- Отдельные бюджеты: общие слова не съедят деньги на свой бренд.
- Свои ставки под разное намерение людей.
- Чистые данные по каждому виду слов.
- Проще остановить или расширить нужную часть.

## Виды совпадения

| Вид | Как работает | Для чего |
|-----|--------------|----------|
| **Точное** | Срабатывает лишь на точный запрос | Ценные и проверенные слова |
| **Широкое** | Срабатывает на варианты и близкие запросы | Поиск новых слов |
| **Search Match** | Apple сама связывает приложение с запросами | Лишь кампания поиска новых слов |

**Ход работы:** возьмите Search Match и широкое совпадение для поиска. Каждую неделю читайте отчёт по запросам. Лучшие переносите в отдельную кампанию с точным совпадением и более высокой ставкой.

## Подбор слов

### Первый список для каждой кампании

**Бренд:**
- точное название приложения;
- частые опечатки;
- имя разработчика.

**Соперники:**
- точные имена пяти-десяти главных приложений;
- ставьте меньше и следите за долей установок: люди, ищущие чужой бренд, реже ставят ваше приложение.

**Категория:**
- частые общие запросы: «приложение для медитации», «учёт привычек», «план расходов»;
- длинные запросы: «медитация против тревоги», «бесплатный учёт привычек на каждый день».

Частоту и сложность проверьте через Appeeky:

```bash
GET /v1/keywords/metrics?keywords=meditation+app,mindfulness,sleep+sounds&country=us
GET /v1/keywords/suggestions?term=meditation&country=us
```

### Минус-слова

Они нужны, чтобы не тратить деньги зря. Добавьте на уровне учётной записи:
- имена соперников, по которым вы не хотите показываться: можно получить плохую долю установок;
- неподходящие слова из Search Match, проверяйте раз в неделю;
- слова с большим числом показов и без нажатий.

## Ставки

### С чего начать

| Кампания | Первая ставка |
|----------|---------------|
| Бренд | Высокая, чтобы выигрывать свои слова: начните с $2–5 |
| Соперники | Средняя: $1–2, следите за CVR |
| Категория | Средняя: $0,80–1,50 |
| Поиск новых слов | Низкая: $0,50–0,80 |

### По каким признакам менять

| Признак | Действие |
|---------|----------|
| Малая доля показов, ниже 50% | Поднять ставку |
| Высокий TTR, но мало установок | Улучшить страницу приложения или экран оплаты |
| Низкий TTR | Картинки или текст не отвечают цели запроса |
| Высокий CVR, но расходы не растут | Поднять ставку или предел бюджета |
| CPT растёт, а CVR нет | Снизить ставку или остановить слово |

**Целевой CPT = Целевой CPI × Прошлый CVR** (установки / нажатия).

### Автоматические ставки

ASA умеет подбирать ставки под целевой CPA или ROAS. Берите их лишь когда:
- группа объявлений даёт от 50 установок за неделю, чтобы хватало данных;
- ручные ставки уже дали отправную точку CPT.

## Creative Product Sets (CPS) и ссылки на CPP

Свяжите **особые страницы приложения** (CPP) с нужными группами объявлений, чтобы показывать картинки под запрос:

```
Группа «приложение для йоги» → CPP со снимками о йоге
Группа «звуки для сна» → CPP со снимками о сне
Группа с именами соперников → CPP со снимками для сравнения
```

**Почему помогает:** человек, ищущий йогу, видит снимки йоги, а не общие снимки приложения. И доля нажатий (TTR), и доля установок (CVR) обычно растут на 15–30%.

Настройка: App Store Connect → Custom Product Pages → создайте страницы → ASA → Ad Group → выберите CPP.

## Показатели и ориентиры

| Показатель | Формула | Ориентир |
|------------|---------|----------|
| **TTR** | Нажатия / Показы | Выше 5% — хорошо; ниже 3% — проверьте картинки |
| **CVR** | Установки / Нажатия | Выше 50% — хорошо; ниже 30% — проверьте страницу |
| **CPT** | Траты / Нажатия | Зависит от категории |
| **CPI** | Траты / Установки | Зависит от категории; сравните с LTV |
| **ROAS** | Доход / Траты | Выше 100% — выгодно; цель — от 150% |

## Еженедельная проверка

```
- [ ] Отчёт Search Terms: перенести лучшие новые слова в кампании с точным совпадением
- [ ] Добавить минус-слова для неподходящих запросов
- [ ] Проверить долю показов по каждому слову и поправить ставки, где она ниже 50%
- [ ] Остановить слова со 100+ нажатиями и без установок
- [ ] Проверить TTR по группам; если он ниже 3%, попробовать новые CPS или CPP
- [ ] Проверить траты: ни одна кампания не должна достичь дневного предела до полудня
- [ ] Сравнить CVR по кампаниям категории, бренда и соперников
```

## Перед ростом бюджета

```
- [ ] CVR главных кампаний выше 30%
- [ ] CPI ниже утроенной целевой цены установки
- [ ] Ручные ставки дают устойчивый результат
- [ ] Список минус-слов поддерживается
- [ ] Проверено хотя бы два варианта CPP
```
