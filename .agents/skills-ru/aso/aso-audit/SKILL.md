# Проверка ASO

Вы разбираетесь в том, как Apple и Google ставят приложения в поиске. Проведите полную проверку ASO и дайте план правок по важности.

## С чего начать

1. Найдите `app-marketing-context.md` и, если он есть, прочитайте сведения о приложении.
2. Спросите **App ID**: число Apple или имя пакета Google Play.
3. Уточните **страну**; по умолчанию — США.
4. Уточните **платформу**: iOS, Android или обе.

## Сбор данных

Если доступен Appeeky MCP или API, получите:
- данные страницы: название, подзаголовок, описание, снимки и оценки;
- нынешние места по поисковым словам;
- сведения о трёх-пяти главных соперниках в категории;
- место в чарте категории;
- общий тон отзывов.

Если доступа нет, попросите пользователя дать нынешние данные страницы.

## Схема проверки

Оцените каждый признак по шкале от 0 до 10. Посчитайте общую оценку ASO как взвешенное среднее.

### 1. Название (вес 20%)

| Проверка | Что искать |
|----------|------------|
| Главное слово | Есть ли в названии запрос № 1? |
| Длина | Близка ли она к 30 знакам на iOS? |
| Бренд и запрос | Имя бренда нужно или лишь занимает место? |
| Читаемость | Звучит ли название естественно, без набора ключевых слов? |
| Особый вид | Отличается ли оно от названий соперников? |

**Оценка:**
- 9–10: главное слово и бренд, естественный текст, почти всё место занято;
- 7–8: нужное слово есть, но текст можно улучшить;
- 4–6: главного слова нет или нарушен баланс;
- 0–3: общее название без нужных слов либо обрезанный текст.

### 2. Подзаголовок (вес 15%) — только iOS

| Проверка | Что искать |
|----------|------------|
| Другие слова | Есть ли вторые по важности слова, которых нет в названии? |
| Без повтора | Не повторяет ли он слова названия? |
| Польза | Говорит ли, что человек получит? |
| Длина | Близка ли она к 30 знакам? |

### 3. Поле ключевых слов (вес 15%) — только iOS

| Проверка | Что искать |
|----------|------------|
| Без повтора | Нет ли слов из названия и подзаголовка? |
| Без пробелов | Есть ли запятые без пробелов после них? |
| Единственное число | Взята ли форма единственного числа, если Apple учитывает обе? |
| Длина | Заполнены ли все 100 знаков? |
| Близость теме | Все ли слова подходят приложению? |
| Нет пустой траты места | Нет ли брендов, названий категорий и слова «приложение»? |

### 4. Описание (вес 5% на iOS / 15% на Android)

| Проверка | Что искать |
|----------|------------|
| Первые три строки | Цепляют ли они до прокрутки? |
| Функции | Показана ли польза, а не только список функций? |
| Частота слов на Android | Встречаются ли нужные запросы естественно во всём тексте? |
| Вид текста | Есть ли абзацы, списки или значки для чтения? |
| Призыв | Есть ли в конце ясное действие? |
| Доверие | Упомянуты ли награды, пресса или число пользователей? |

### 5. Снимки экрана (вес 15%)

| Проверка | Что искать |
|----------|------------|
| Число | Заняты ли все десять мест? |
| Первые три | Стоят ли впереди самые сильные функции? |
| Текст поверх | Ясно ли написана польза, можно ли прочесть? |
| Единый стиль | Сочетаются ли снимки между собой? |
| Перевод | Подстроены ли они под нужную страну? |
| Рамка устройства | Современная ли она, если есть? |

### 6. Видео предпросмотра (вес 5%)

| Проверка | Что искать |
|----------|------------|
| Наличие | Есть ли видео? |
| Первые три секунды | Есть ли зацепка сразу? |
| Длина | Попадает ли она в удачный промежуток 15–30 секунд? |
| Звук | Понятно ли видео без звука благодаря субтитрам? |

### 7. Оценки и отзывы (вес 15%)

| Проверка | Что искать |
|----------|------------|
| Средняя оценка | Не ниже 4,5 звезды? |
| Число оценок | Хватает ли их для категории? |
| Новые отзывы | Хороший ли ход за последние 30 дней? |
| Ответы | Отвечает ли автор на плохие отзывы? |
| Просьба оценить | Просит ли приложение дать оценку в подходящий момент? |

### 8. Значок (вес 5%)

| Проверка | Что искать |
|----------|------------|
| Отличие | Заметен ли он в поиске? |
| Простота | Ясен ли в малом размере? |
| Близость категории | Соответствует ли ожиданиям людей в категории? |
| Без текста | Нет ли мелкого нечитаемого текста? |

### 9. Места по ключевым словам (вес 10%)

| Проверка | Что искать |
|----------|------------|
| Первая десятка | Входит ли приложение в неё по нужным запросам? |
| Охват слов | Находится ли по достаточному числу подходящих слов? |
| Ход | Места растут или падают? |
| Пробелы | Есть ли слова, по которым находятся соперники, а ваше приложение — нет? |

### 10. Признаки, влияющие на установки (вес 5%)

| Проверка | Что искать |
|----------|------------|
| Рекламный текст | Обновляется ли он под текущие события? |
| «Что нового» | Есть ли свежие, полезные записи об обновлениях? |
| События внутри приложения | Применяются ли они для видимости? |
| Особые страницы продукта | Есть ли разные страницы для разных групп людей? |

### Сильные правки — на этой неделе
