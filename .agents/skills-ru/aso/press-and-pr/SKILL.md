# Пресса и связи с ней для приложений

Помогайте небольшим разработчикам и командам получить настоящие публикации. Они приносят установки, ссылки на сайт и доверие к приложению в App Store.

## Почему пресса всё ещё важна

- **Переходы с сайтов** в App Store Connect позволяют увидеть установки по ссылкам из статей.
- **Ссылки с сильных сайтов**, например TechCrunch и The Verge, помогают сайту приложения быть заметнее.
- **Доверие:** надпись «О нас писали...» на странице приложения может поднять долю установок.
- **Редакция Apple:** статьи повышают шансы на её подборки.
- **Рост без оплаты:** люди делятся статьями, и о приложении узнают за пределами исходного издания.

## Какие издания брать

### Первый ряд — сильный эффект, труднее попасть

| Издание | Тема | Примечание |
|---------|------|------------|
| TechCrunch | Техника для людей, новые компании | Предпочитает особые материалы |
| The Verge | Техника для людей | Строгий отбор |
| Wired | Техника и культура | Нужна необычная тема для большой статьи |
| Fast Company | Новые идеи и работа | Важна деловая сторона |
| 9to5Mac | Приложения iOS/macOS | Пишет об отдельных приложениях, проще обратиться |
| MacStories | Приложения iOS | Открыто к небольшим авторам |

### Второй ряд — проще обратиться, охват всё ещё важен

| Вид | Примеры |
|-----|---------|
| Сайты с обзорами | AppAdvice, TouchArcade для игр, AppShopper |
| Узкие почтовые издания | Рассылки о здоровье, работе, финансах и других темах приложения |
| Каналы YouTube | AppFind, MKBHD для важных приложений, каналы по узкой теме |
| Подкасты | Передачи о приложениях и другие по теме |

### Третий ряд — начните здесь

| Вид | Примеры |
|-----|---------|
| Reddit | r/iphone, r/androidapps, r/productivity и сообщества своей категории |
| Product Hunt | Видимость в день выхода |
| Hacker News | Запись Show HN для технических и рабочих приложений |
| Indie Hackers | Сообщество независимых авторов |

## О чём может быть история

Пресса пишет не просто о приложениях, а об **историях**. Найдите свою тему:

| Подход | Пример |
|--------|--------|
| **Числа** | «Приложение набрало 100 тысяч загрузок за семь дней без рекламы» |
| **Решённая задача** | «Один разработчик сделал X, потому что другие средства не умели Y» |
| **Свои данные** | «Мы изучили 10 млн записей о привычках — вот что узнали» |
| **Новая категория** | «Мы придумали новый вид приложений для [задачи]» |
| **Малый против большого** | Независимый автор обошёл крупную компанию |
| **Момент** | Связь с нынешней новостью или событием в культуре |
| **Личная история** | Сильная причина автора создать приложение |

**Проверка темы:** можно ли объяснить её одним предложением, после которого человек скажет «интересно»?

## Набор материалов для прессы

Создайте папку `presskit/` на сайте или открытую страницу Notion:

```
Что положить:
- [ ] Название приложения, суть в одной строке, категория
- [ ] Три фото автора в хорошем разрешении для печати
- [ ] Значок приложения: PNG 1024×1024px
- [ ] От 5 до 10 снимков: макеты телефона в хорошем разрешении
- [ ] Видео приложения: необязательно, но полезно
- [ ] Сведения о команде или авторе в трёх предложениях
- [ ] Главные числа: загрузки, оценки, известные пользователи
- [ ] Цитаты из прессы и прежние статьи, если есть
- [ ] Ссылка на App Store и сайт
- [ ] Почта для прессы
```

Разместите на `yoursite.com/press` либо дайте открытую ссылку Notion или Google Drive.

## Устройство пресс-релиза

```
ДЛЯ НЕМЕДЛЕННОЙ ПУБЛИКАЦИИ

[Заголовок — самая важная новость как утверждение]
[Подзаголовок — поясняющий факт]

[Город, дата] — [Начало: что случилось и почему это важно]

[Абзац 1: новость — кто, что, когда и где]

[Абзац 2: зачем это нужно — проблема, история и особый подход]

[Абзац 3: слова автора]
«[Живая цитата, а не повтор фактов]» — [имя, роль, компания]

[Абзац 4: главные функции или числа — не больше трёх]

[Абзац 5: где взять, цена, платформы]
[Приложение] доступно на [iOS/Android/обеих] [бесплатно/за цену]. Ссылка: [App Store].

###

О [компании]:
[Два-три предложения]

Для прессы:
[Имя] | [почта] | [телефон, если нужен]
```

## Как писать журналистам

### Первое письмо без знакомства

```
Тема: [Название приложения] — [ваша тема в восьми словах]
Например: «Аналог Habitica стал первым в категории „Здоровье“ без рекламы»

Здравствуйте, [имя]!

[Одно предложение: почему вы пишете именно этому автору]
Например: «Прочитал вашу статью о [недавнем материале]; [приложение] близко к этой теме».

[Одно предложение: что делает приложение]
[Одно предложение: тема истории, самый интересный факт или число]
[Одно предложение: почему это важно сейчас]

Могу прислать код доступа, набор для прессы или коротко созвониться.

[Ваше имя]
[Ссылка на App Store]
[Ссылка на материалы для прессы]
```

**Правила:**
- В первом письме не больше пяти предложений.
- Первую строку пишите лично для каждого журналиста, не делайте общую рассылку.
- Не прикрепляйте файлы, дайте ссылку на материалы для прессы.
- Пишите со вторника по четверг в 8–10 утра по времени адресата.
- Если ответа нет, напомните один раз через пять рабочих дней и переходите дальше.

### Как найти нужных журналистов

1. Найдите в издании недавние обзоры приложений вашей категории.
2. Посмотрите имя автора и пишите именно ему.
3. Проверьте в профиле Twitter/X, хочет ли он получать личные сообщения.
4. Для поиска почты можно взять Hunter.io; пример схемы адреса — first@publication.com.

## Запрет на раннюю публикацию

Для крупного выхода можно предложить материал с условием не публиковать до дня выпуска:

- Напишите журналистам за одну-две недели.
- Дайте особый ранний доступ с датой снятия запрета: статья выйдет в день выпуска.
- Предлагайте одну особую тему одному журналисту в каждом ряду, не обещайте её сразу двум соперничающим изданиям.
- Дайте доступ к TestFlight или пробной версии Play.

Особые материалы сильно повышают шанс публикации в изданиях первого ряда.

## Выход на Product Hunt

| Шаг | Когда | Действие |
|-----|-------|----------|
| Сделать страницу «Скоро» | За две недели | Включить сбор подписчиков до выхода |
| Найти автора публикации | За неделю | Попросить влиятельного участника PH представить продукт |
| Подготовить материалы | За три дня | Галерея, короткая фраза, описание и первый комментарий |
| День выхода | Со вторника по четверг | Опубликовать в 00:01 по тихоокеанскому времени и весь день отвечать людям |
| Рассказ об итогах | Через неделю | Поделиться результатом в Show HN или историей автора |

## Вид ответа

### План работы с прессой

```
Тема истории: [одно предложение]

Кому писать:
  Первый ряд: [издание и имя журналиста]
  Второй ряд: [два-три блога или рассылки]
  Третий ряд: Product Hunt, Reddit r/[категория], HN

Сроки:
  За 14 дней: собрать материалы для прессы и написать пресс-релиз
  За 10 дней: предложить первому ряду ранний материал с датой публикации
  За 7 дней: напомнить не ответившим и написать второму ряду
  День выхода: публикация, Product Hunt и сообщения в третьем ряду
  Через 3 дня: поблагодарить авторов, опубликовать ссылки на статьи

Материалы для прессы: [ссылка]
Почта для прессы: [адрес]
```

## Связанные навыки

- `app-launch` — полный план выхода, где пресса лишь один путь.
- `app-store-featured` — статьи помогают попасть в выбор редакции Apple.
- `ua-campaign` — дополните публикации платной рекламой на неделе выхода.
