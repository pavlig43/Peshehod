Правила сохранения мешают R8 улучшать код. Ниже они расположены по широте кода, который сохраняют.

## 1. Маски для целых пакетов

Такие правила мешают улучшить весь пакет. Избегайте их и сужайте до нужных классов:

```proguard
-keep class com.example.package.** { *; } # Все классы и члены пакета с подпакетами.
-keep class com.example.package.* { *; }  # Все классы и члены одного пакета.
-keep class **.package.** { *; }          # Все классы и члены каждого пакета с именем package.
```

Чем выше пакет в дереве, тем больше классов затронуто. Предлагайте сузить такое правило.

## 2. Оператор отрицания

Избегайте `!` в правилах сохранения: он может по ошибке запретить улучшение всех классов приложения. Если он есть, замените правило узким и точным:

```proguard
-keep class !com.example.MyClass{*;}
```

Это правило сохраняет всё приложение, кроме указанного класса. Улучшение отключено для всех остальных классов.

## 3. Класс со всеми членами

Правило `-keep` с маской `*` внутри фигурных скобок сохраняет указанные классы вместе со всеми членами в точности как задано. Оно мешает любым улучшениям всего класса:

```proguard
-keep class com.example.MyClass { *; }
```

## 4. Все члены класса

Правило `-keepclassmembers` с маской `*` внутри скобок заставляет R8 сохранить все члены указанного класса:

```proguard
-keepclassmembers class com.example.MyClass { *; }
```

## 5. Сохранение с разрешающими параметрами

Правило сохраняет класс и **все** его члены, но разрешает отдельные улучшения, например смену имён. Оно оставляет много кода, хотя даёт R8 часть свободы:

```proguard
-keep,allowobfuscation class com.example.MyClass { *; }
-keep,allowshrinking class com.example.MyClass { *; }
```

## 6. Конкретный метод без разрешающих параметров

Сохраняет класс и указанный член без разрешения улучшений:

```proguard
-keep class com.example.MyClass { void myMethod(); }
```

## 7. Только имя класса

Сохраняет лишь имя класса. R8 может убрать методы и поля, которые нигде не используются:

```proguard
-keep class com.example.MyClass
```

## 8. Разрешающие параметры без списка членов

Сохраняет точку входа класса с указанным разрешением, но само правило не требует сохранять конкретные члены:

```proguard
-keep,allowobfuscation class com.example.MyClass
-keep,allowshrinking class com.example.MyClass
-keep,allowaccessmodification class com.example.MyClass
```

## 9. Условные правила

Действуют лишь при выполнении условия, например если в классе есть нужные члены. Это самые узкие правила, которые лучше всего оставляют возможность для улучшений:

```proguard
-keepclassmembers class com.example.MyClass { <fields>; }
-keepclasseswithmembers class * { native <methods>; }
```
