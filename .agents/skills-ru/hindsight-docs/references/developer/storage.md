# Хранилище

Основное хранилище Hindsight — PostgreSQL. Для крупных компаний есть и другой вариант: Oracle AI Database.

## Почему PostgreSQL?

В одной базе PostgreSQL есть всё, что нужно системе смысловой памяти:

| Возможность | Реализация |
|------------|----------------|
| Поиск по векторам | Расширение pgvector и индексы HNSW |
| Полнотекстовый поиск | Встроенный tsvector и индексы GIN |
| Связанные данные | Средства PostgreSQL |
| Документы JSON | JSONB с индексами |
| Запросы к графу | Рекурсивные CTE |

### Меньше зависимостей

Опора на одну базу упрощает запуск и поддержку:

- Одно подключение к базе
- Один способ резервного копирования и восстановления
- Один объект для слежения за работой
- Транзакции ACID для всех типов данных
- Один путь обновления

### Без общего слоя хранилищ

Hindsight не скрывает хранилище за общим интерфейсом. Это осознанный выбор.

Мы считаем, что PostgreSQL становится общим интерфейсом баз данных. Популярность, набор расширений и модульность привели к тому, что совместимые с PostgreSQL интерфейсы есть повсюду: от бессерверных служб до распределённых баз. Работа напрямую с PostgreSQL сегодня даёт доступ к растущей среде завтра.

Поддержка нескольких баз дала бы больше выбора, но помешала бы главной цели: Hindsight полностью открыт и должен быть простым в запуске и работе. Общий слой баз усложнил бы код, тесты, документы и поддержку — а с этой сложностью пришлось бы иметь дело пользователям.

Опора на PostgreSQL сохраняет простоту:
- Одни указания по запуску
- Один набор свойств быстродействия, который нужно изучить
- Одна кодовая база, настроенная под одно хранилище
- Не нужно выбирать базу при настройке

### Поддержка Oracle AI Database

Для крупных компаний Hindsight также поддерживает Oracle AI Database со всеми теми же функциями. Операции retain, recall и reflect работают на Oracle так же, поэтому компании, которые уже используют Oracle, могут взять её вместо PostgreSQL.

## Разработка с pg0

Для местной разработки Hindsight использует **[pg0](https://github.com/vectorize-io/pg0)** — встроенный дистрибутив PostgreSQL.

### Что такое pg0?

pg0 — один исполняемый файл, в который входят:
- Сервер PostgreSQL
- Уже установленное расширение pgvector
- Автоматическая начальная настройка

### Поведение

Если `HINDSIGHT_API_DATABASE_URL` не задан, Hindsight:
1. Запускает встроенный PostgreSQL на порту 5555
2. Создаёт схему базы
3. Хранит данные в `~/.hindsight/pg0/`

### Среды

| Среда | База данных | Настройка |
|-------------|----------|---------------|
| Разработка | pg0 (встроена) | Автоматически |
| Рабочая среда | PostgreSQL 15+ | Переменная среды `HINDSIGHT_API_DATABASE_URL` |

## Требования

- PostgreSQL 15 или новее
- pgvector 0.5.0 или новее

Подойдёт любой экземпляр PostgreSQL, который отвечает этим требованиям. Если с вашим набором возникла проблема, [создайте обращение на GitHub](https://github.com/hindsight-ai/hindsight/issues).

### Проверенные управляемые службы

- AWS RDS (PostgreSQL 15+)
- Google Cloud SQL
- Azure Database for PostgreSQL
- Supabase
- Neon
