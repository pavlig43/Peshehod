## [0.1.0](https://github.com/vectorize-io/hindsight/tree/main/hindsight-integrations/cursor)

**Новые возможности**

- Добавлен плагин памяти Hindsight для Cursor: хуки Cursor автоматически извлекают и сохраняют воспоминания.
- Добавлены средства для Cursor: постоянно действующее правило и навык `hindsight-recall`, запускаемый по запросу.
- Добавлена поддержка локальной фоновой службы, внешних API Hindsight и встроенного MCP как другого способа подключения.
- Добавлены автотесты загрузки настроек, вычисления банка памяти, форматирования текста и работы хуков.
