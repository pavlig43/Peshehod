# Доступность и контраст

Контраст всегда измеряют между **цветом переднего плана** — текста, значка или части интерфейса — и **фоном**, на котором его показывают. Для проверки найдите настоящий фон элемента, обычно цвет фона ближайшего родителя.

**Сообщайте о проблеме, не перекрашивайте без запроса.** Если пара не проходит проверку, укажите оба цвета, измеренное значение Lc или отношение и нужный порог. Оставьте цвета как есть. Палитра проекта — решение по дизайну; правьте её по правилам ниже, лишь если пользователь попросил исправить контраст.

## Пороги APCA (советуемые)

APCA — алгоритм контраста с учётом зрительного восприятия. Он лучше отражает то, как люди видят цвета, чем WCAG 2, и хорошо сочетается с oklch: оба основаны на светлоте, видимой человеку. По умолчанию берите APCA.

Lc (Lightness Contrast) измеряет видимый контраст текста и фона. Ниже — упрощённые пороги из полной таблицы APCA, где учтены размер и вес шрифта:

| Вид содержимого | Минимум | Желательно |
| --- | --- | --- |
| Основной текст (столбцы и блоки) | Lc 75 | Lc 90 |
| Прочий текст (подписи и заголовки) | Lc 60 | Lc 75 |
| Крупный текст (≥36px) | Lc 45 | Lc 60 |
| Элементы интерфейса | Lc 30 | Не задано |

Lc 30 — также минимум APCA для выключенного текста и подсказок внутри полей. Нижний предел, при котором нетекстовый элемент вообще заметен, — Lc 15.

У Lc есть знак: плюс означает тёмный текст на светлом фоне, минус — светлый текст на тёмном. Для сравнения с порогом берите модуль числа.

## Пороги WCAG 2 (для формальной проверки)

Если нужно официально заявить соответствие WCAG 2.x, проверяйте и WCAG 2. Он измеряет отношение яркостей и в зависимости от пары цветов может быть как слишком строгим, так и слишком мягким.

| Вид содержимого | AA | AAA |
| --- | --- | --- |
| Обычный текст (<24px / <18.5px жирным) | 4.5:1 | 7:1 |
| Крупный текст (≥24px / ≥18.5px жирным) | 3:1 | 4.5:1 |
| Элементы интерфейса и графика | 3:1 | Не задано |

WCAG задаёт «крупный текст» в пунктах: 18pt ≈ `24px`, либо 14pt жирным ≈ `18.5px`.

## Как исправить контраст через oklch (по запросу)

В hex/rgb для правки контраста приходится подбирать три канала. В oklch сперва меняйте светлоту L: увеличьте разницу L между передним планом и фоном, по мере сил сохраняя C и H:

```css
/* Failing: text too close in lightness to its background (Lc ≈ 50) */
color: oklch(0.65 0.08 250);      /* foreground */
background: oklch(0.95 0.02 250); /* background */

/* Fix: darken the text, keep C and H unchanged (Lc ≈ 90) */
color: oklch(0.3 0.08 250);       /* foreground: more L distance */
background: oklch(0.95 0.02 250); /* background: unchanged */
```

На фоне средней светлоты возможный контраст ограничен. При L фона 0.75 даже чисто чёрный текст даст лишь около Lc 60. Для основного текста нужен фон ближе к светлому или тёмному краю шкалы.

Сначала подстройте L, потом вновь измерьте готовую пару цветов. Цветность и тон тоже могут влиять на итог после перевода в цветовое пространство, обрезку по его охвату и измеренный контраст. Если нужно, снизьте C, чтобы новый цвет остался в охвате.

## Быстрый ориентир по разнице светлоты

Для основного текста с целью |Lc| ≥ 75:

- **Светлый фон (L > 0.9):** у текста L должна быть ниже 0.35.
- **Тёмный фон (L < 0.25):** у текста L должна быть выше 0.9.

Разница несимметрична: APCA учитывает, что светлый текст на тёмном фоне виден иначе, чем тёмный на светлом. Это лишь примерные числа — всегда проверяйте расчётом контраста.

## Как отличить светлый фон от тёмного

Для нейтрального фона граница APCA проходит при светлоте oklch 0.73:

```
if L > 0.73 → use dark text on this background
if L <= 0.73 → use light text on this background
```

Граница выше, чем можно ожидать: при L от 0.6 до 0.73 фон уже выглядит светлым, но белый текст всё ещё получает заметно более высокую оценку, чем чёрный.

## Как найти смещение тона

Чтобы найти смещение тона в готовой палитре HSL:

1. Переведите каждую ступень в oklch.
2. Сравните значения H у ступеней.
3. Если разброс тона больше 10°, смещение заметно на глаз.

```css
/* HSL blue ramp: hue shifts toward purple */
hsl(240, 80%, 20%)  →  oklch H ≈ 269
hsl(240, 80%, 50%)  →  oklch H ≈ 267
hsl(240, 80%, 90%)  →  oklch H ≈ 285  /* shifted 18° */
```
