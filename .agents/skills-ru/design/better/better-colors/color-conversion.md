# Перевод цветов в другой формат

Обращайтесь к этому справочнику, лишь когда пользователь просит перевести цвета в другой формат, проект уже переходит на OKLCH или это часть согласованного перехода всей палитры. Не меняйте одно значение в проекте, где другой формат выбран намеренно. Если перевод нужен, меняйте только значения цветов: не трогайте способ смешивания градиента и структуру CSS.

## Поддерживаемые форматы на входе

| Формат | Примеры |
| --- | --- |
| Hex (3, 6 или 8 знаков) | `#f00`, `#ff0000`, `#ff000080` |
| `rgb()` / `rgba()` | `rgb(255, 0, 0)`, `rgba(255, 0, 0, 0.5)` |
| `hsl()` / `hsla()` | `hsl(0, 100%, 50%)`, `hsla(0, 100%, 50%, 0.5)` |

## Примеры перевода

```css
/* Before */
color: #3b82f6;
background: #1e293b;
border-color: #e2e8f0;

/* After */
color: oklch(0.623 0.188 259.815);
background: oklch(0.279 0.037 260.031);
border-color: oklch(0.929 0.013 255.508);
```

```css
/* Before */
color: rgb(59, 130, 246);
border: 1px solid rgba(0, 0, 0, 0.1);

/* After */
color: oklch(0.623 0.188 259.815);
border: 1px solid oklch(0 0 0 / 0.1);
```

Прозрачность задаётся через косую черту. При значении 1 её можно опустить.

## Что оставить без правок

- Ключевые слова CSS: `currentColor`, `inherit`, `initial`, `unset`, `transparent`.
- Способ смешивания в градиентах: переводите лишь цвета в опорных точках, не саму функцию.
- Цвета в настройках сторонних библиотек, которые принимают hex.

## Массовый перевод

Массовый перевод — это отдельная задача по смене формата, а не рядовая чистка. Если в область задачи явно входит весь файл:

1. Замените все цвета hex на равные им значения oklch.
2. Замените все вызовы `rgb()`, `rgba()`, `hsl()` и `hsla()`.
3. Не меняйте функции градиентов; переводите лишь цвета внутри них.
4. Оставьте `currentColor`, `inherit`, `transparent` и другие ключевые слова CSS без правок.
5. Сохраните комментарии и форматирование.
