# Создание палитры

## Числовая шкала

В дизайн-системах палитру обычно размечают числами от 50 (самый светлый) до 950 (самый тёмный). Номера ступеней зависят от их числа:

| Число ступеней | Номера |
| --- | --- |
| 5 | 100, 300, 500, 700, 900 |
| 9 | 50, 100, 200, 300, 500, 700, 800, 900, 950 |
| 11 | 50, 100, 200, 300, 400, 500, 600, 700, 800, 900, 950 |

Шкала из 11 ступеней совпадает с обычной шкалой Tailwind. Если промежуточные `400` и `600` не нужны, хватит 9 ступеней.

## Алгоритм

Пусть задан исходный цвет со светлотой L, процентом цветности и тоном H.

**Шаг 1. Задайте границы светлоты:**

```
delta = 0.4
minL = max(0.05, baseL - delta)
maxL = min(0.95, baseL + delta)
```

Светлота остаётся в пределах [0.05, 0.95], чтобы избежать чисто чёрного и белого: у них нулевая цветность.

**Шаг 2. Распределите светлоту** равномерно от maxL (самая светлая ступень 50) до minL (самая тёмная ступень 950).

**Шаг 3. Ограничьте цветность для каждой ступени.** У каждой светлоты свой предел цветности для заданного тона и цветового пространства:

```
maxChroma = findMaxChroma(step[i].L, hue, colorSpace)
step[i].C = (chromaPercentage / 100) * maxChroma
```

Так каждая ступень остаётся в цветовом охвате. У очень яркого исходного цвета крайние светлые и тёмные ступени будут менее насыщенными. Это ожидаемо.

## Вывод в переменные CSS

```css
:root {
  --color-50: oklch(0.971 0.012 250);
  --color-100: oklch(0.932 0.028 250);
  --color-200: oklch(0.882 0.048 250);
  --color-300: oklch(0.812 0.078 250);
  --color-500: oklch(0.623 0.188 250);
  --color-700: oklch(0.445 0.138 250);
  --color-800: oklch(0.362 0.108 250);
  --color-900: oklch(0.289 0.078 250);
  --color-950: oklch(0.215 0.048 250);
}
```

## Палитра из нескольких тонов

Для разных тонов берите одни и те же **светлоту** и **процент цветности**. Одинаковая L даёт равную на вид яркость. Одинаковый процент цветности относительно предела каждого тона — равную на вид насыщенность. Абсолютное значение цветности здесь не подходит.

```css
:root {
  /* Same L, same C% (80% of max): different absolute C per hue */
  --blue-500: oklch(0.623 0.141 250);   /* 80% of max 0.176 */
  --green-500: oklch(0.623 0.157 145);  /* 80% of max 0.196 */
  --red-500: oklch(0.623 0.202 25);     /* 80% of max 0.253 */
}
```

При одной светлоте разные тона имеют разный предел цветности. Если всем дать одну абсолютную C, часть цветов будет казаться ярче остальных.

## Тёмная тема

Начните со смены ролей светлых и тёмных цветов, затем подстройте значения для тёмного вида:

```css
:root {
  --color-bg: var(--color-50);
  --color-text: var(--color-950);
}

.dark {
  --color-bg: var(--color-950);
  --color-text: var(--color-50);
}
```

Не переворачивайте всю шкалу механически. В тёмной теме часто нужны иная цветность и другие шаги светлоты. Равные шаги OKLCH не дают равный контраст для каждой пары текста и фона. Проверьте каждую пару и при нужде отдельно настройте токены тёмной темы.

## Почему не палитра HSL?

**Смещение тона:** `hsl(240, 80%, 20%)` и `hsl(240, 80%, 90%)` не выглядят одним и тем же тоном. Светлый вариант уходит примерно на 16° к фиолетовому. Тон OKLCH устойчивее.

**Разная яркость:** `hsl(60, 100%, 50%)` (жёлтый) и `hsl(240, 100%, 50%)` (синий) имеют одну светлоту HSL, но выглядят очень разными по яркости.
