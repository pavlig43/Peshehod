# Применение цвета

Как применять цвет в интерфейсе: имена по смыслу, значения, акценты и варианты оформления. Выбор самих значений описан в [palette-generation.md](palette-generation.md), проверка пар — в [accessibility-contrast.md](accessibility-contrast.md).

## Один цвет — один смысл

Применяйте цвет для одной цели во всём интерфейсе: действие, удаление, особое выделение. Если фирменный цвет означает ссылку, тот же тон (в пределах ±15°) у текста без действия заставит людей нажимать на то, что не нажимается.

```css
/* Bad: brand blue means both "link" and "decorative heading" */
a { color: oklch(0.623 0.188 259.815); }
.section-title { color: oklch(0.65 0.17 259.815); }

/* Good: interactive elements own the brand hue; headings stay neutral */
a { color: oklch(0.623 0.188 259.815); }
.section-title { color: oklch(0.279 0.041 260.031); }
```

## Имена цветов по роли, а не по значению

Называйте цвет по его роли и применяйте лишь для неё. `--color-text-secondary` — приглушённый цвет текста. Если взять его для фона, при смене темы сломается смысл этой переменной.

```css
/* Good: tokens named by role, used in that role */
:root {
  --color-text-primary: oklch(0.21 0.006 285.885);
  --color-text-secondary: oklch(0.552 0.016 285.938);
  --color-separator: oklch(0.92 0.004 286.32);
  --color-surface: oklch(1 0 0);
}

/* Bad: separator token repurposed as text color because it "looked right" */
.caption { color: var(--color-separator); }

/* Bad: secondary-text token repurposed as a background */
.tag { background: var(--color-text-secondary); }
```

Если для нужной роли нет переменной, добавьте её. Не берите чужую только потому, что её значение сегодня подходит. В Tailwind такие переменные задают в блоке `@theme`; см. [gamut-and-tailwind.md](gamut-and-tailwind.md).

## Одно цветное главное действие на экран

Если заливка цветом в продукте отмечает главное действие, дайте её одной главной кнопке в текущем выборе, а соседние оставьте нейтральными. Если в проекте уже есть иная ясная система важности элементов, сохраните её. Не перекрашивайте кнопки только ради этого правила. Несколько цветных фонов допустимы, когда они означают разные состояния или категории и не борются за внимание как равные действия.

```html
<!-- Good: one filled primary action, neutral secondaries -->
<button class="bg-blue-600 text-white">Save</button>
<button class="text-zinc-700">Cancel</button>

<!-- Bad: every action colored, so nothing is primary -->
<button class="bg-blue-600 text-white">Save</button>
<button class="bg-blue-600 text-white">Duplicate</button>
<button class="bg-blue-600 text-white">Export</button>
```

Кладите цвет на фон, а не только на надпись. Залитая кнопка `bg-blue-600 text-white` видна как главная издалека; синяя надпись на нейтральной кнопке похожа на ссылку. Выбранное состояние — активная вкладка или нажатый переключатель — может окрашивать знак и подпись: это указание состояния, а не важности.

## Цвет в разных культурах

Значение цвета зависит от культуры. Если от него зависит смысл в финансах, статусах или тревожных сообщениях, проверьте его для каждой страны, куда выходит продукт.

| Цвет | Частый смысл на Западе | Где-то ещё |
| --- | --- | --- |
| Красный | Опасность, потеря, ошибка | Удача, достаток; **рост** в китайских финансовых интерфейсах |
| Зелёный | Успех, рост, движение | Потери в китайских финансовых интерфейсах |
| Белый | Чистота | Траур в части Восточной Азии |
| Золотой | Дорогой, роскошный | Религиозный смысл в части стран |

Частый пример: в английских версиях биржевой рост окрашен зелёным, в китайских — красным. Если продукт выходит на такие рынки, задавайте цвета роста и спада по языку и стране, а не жёстко в коде.

## Светлая и тёмная темы, высокий контраст

Для каждого своего цвета нужны светлый и тёмный варианты. Как выводить тёмные цвета, описано в [palette-generation.md](palette-generation.md). Людям, включившим высокий контраст, нужна более заметная разница; добавьте её через `prefers-contrast`:

```css
:root {
  --color-accent: oklch(0.623 0.188 259.815);
}

@media (prefers-color-scheme: dark) {
  :root { --color-accent: oklch(0.707 0.165 254.624); }
}

@media (prefers-contrast: more) {
  :root { --color-accent: oklch(0.488 0.243 264.376); }
}
```

В режиме высокого контраста разница светлоты между текстом и фоном должна быть хотя бы на `0.15` L больше обычной. Затем ещё раз проверьте пару по желаемым порогам APCA: Lc 90 для основного текста, Lc 75 для остального.

Два правила проверки:

- **Проверьте каждую пару текста и фона в обеих темах.** Пара, которая проходит проверку в светлой теме, может не пройти её в тёмной: палитры не зеркальны.
- **Учитывайте прозрачность.** Цвет на полупрозрачном слое, например шапке с `backdrop-filter`, меняется вместе с тем, что прокручивается позади. Проверьте его на самом светлом и самом тёмном возможном содержимом либо сделайте слой достаточно плотным, чтобы контраст не портился.
