# Цветовой охват и Tailwind v4

## sRGB и Display P3

Все цвета sRGB входят в Display P3, но не все цвета P3 входят в sRGB. Display P3 охватывает примерно на 50% больше цветов.

## Предел насыщенности зависит от светлоты и тона

Граница цветового охвата неровная. При L=0.5 в sRGB:

- Наибольшая цветность — у фиолетового (H ≈ 285): C ≈ 0.29.
- У красно-оранжевого (H ≈ 0–30): C ≈ 0.20.
- Наименьшая цветность — у голубого (H ≈ 195): C ≈ 0.09.

Тон с наибольшей цветностью меняется вместе со светлотой. При L=0.7 лидирует пурпурный, при L=0.9 — зелёный. У голубого предел цветности остаётся самым низким.

## Проверка цветового охвата

Если цветность превышает предел для заданных L, H и цветового пространства, значение обрезается. Уменьшите цветность, сохранив L и H.

```css
/* Out of sRGB gamut */
oklch(0.7 0.35 150)

/* Clamped to max chroma */
oklch(0.7 0.22 150)
```

## Запасные цвета в CSS

```css
/* sRGB fallback for all browsers */
.accent {
  color: oklch(0.7 0.2 150);
}

/* P3 enhancement for wider gamut displays */
@media (color-gamut: p3) {
  .accent {
    color: oklch(0.7 0.3 150);
  }
}
```

Для браузеров без поддержки oklch:

```css
.accent {
  color: #4ade80;
}

@supports (color: oklch(0 0 0)) {
  .accent {
    color: oklch(0.7 0.2 150);
  }

  @media (color-gamut: p3) {
    .accent {
      color: oklch(0.7 0.3 150);
    }
  }
}
```

## Tailwind v4

Палитра Tailwind CSS v4 задана в oklch. Для своих тем придерживайтесь того же формата.

### Своя шкала цветов через @theme

```css
@theme {
  --color-brand-50: oklch(0.971 0.012 250);
  --color-brand-100: oklch(0.932 0.028 250);
  --color-brand-200: oklch(0.882 0.048 250);
  --color-brand-300: oklch(0.812 0.078 250);
  --color-brand-400: oklch(0.722 0.148 250);
  --color-brand-500: oklch(0.623 0.188 250);
  --color-brand-600: oklch(0.535 0.168 250);
  --color-brand-700: oklch(0.445 0.138 250);
  --color-brand-800: oklch(0.362 0.108 250);
  --color-brand-900: oklch(0.289 0.078 250);
  --color-brand-950: oklch(0.215 0.048 250);
}
```

Такая шкала сама даёт классы `bg-brand-500`, `text-brand-200` и другие.

### Модификаторы прозрачности

Запись Tailwind для прозрачности работает и с oklch:

```html
<div class="bg-brand-500/50"></div>
<!-- Compiles to: oklch(0.623 0.188 250 / 0.5) -->
```

### Перенос готовых тем

1. Переведите все значения hex в `@theme` в oklch.
2. Замените ссылки `theme()`, которые опирались на hex.
3. Проверьте тёмную тему: из-за особенностей восприятия значения oklch могут выглядеть чуть иначе.
4. Найдите жёстко заданные цвета hex в коде элементов и переведите их тоже.
