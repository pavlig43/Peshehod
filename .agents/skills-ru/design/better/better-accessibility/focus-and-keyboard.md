# Фокус и клавиатура

Рамка фокуса, ссылка для пропуска меню, `tabindex`, удержание фокуса в окне и клавиши по правилам APG.

## Рамка фокуса

Оформляйте `:focus-visible`, а не общий `:focus`. Браузер показывает `:focus-visible` при работе с клавиатуры и со вспомогательными средствами, но скрывает после нажатия мышью, когда место действия и так ясно. Не пишите `outline: none` или `focus:outline-none` без видимой замены: иначе зрячие люди с клавиатурой не увидят, где находятся.

Лучше оставить родную рамку браузера: она подстроится под платформу и режим принудительных цветов, даже если вы не предвидели каждый фон. Обычно хватает `outline-offset`. Своя рамка `outline: 2px solid` без цвета берёт `currentColor`, но это не даёт доступность само по себе: рамка может пересекать цвета, отличные от фона текста. Порядок выбора такой:

```css
/* Best: keep the browser ring, just give it breathing room */
:focus-visible {
  outline-offset: 2px;
}

/* Custom ring when the design requires one: use the project's verified token */
:focus-visible {
  outline: 2px solid var(--focus-ring);
  outline-offset: 2px;
}
```

```tsx
// Tailwind: use the project's focus token or established focus-ring utility
<button className="focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-[var(--focus-ring)]">
  Save
</button>
```

Своя рамка должна пройти требования проекта и WCAG по видимой площади и смене контраста. Проверьте весь её контур на всех соседних цветах: заливке элемента, фоне страницы, картинках, градиентах, состояниях наведения и выбора. Цвет переменной, бренда или `currentColor` годится лишь после такой проверки готового вида.

В режиме `forced-colors: active` (высокий контраст Windows) оставьте родную подстройку цветов или явно возьмите системный цвет вроде `Highlight`. Не фиксируйте свой цвет через `forced-color-adjust: none`, если после этого элемент плохо виден.

Берите `:focus-within`, когда вся обёртка должна выделяться при фокусе вложенного поля, например поиск со значком внутри рамки.

## Ссылка для пропуска меню

Если перед главным текстом снова и снова идут меню и шапка, первым элементом для фокуса должна быть ссылка «К содержимому» на `<main id="main">`. Скройте её зрительно до появления фокуса:

```css
.skip-link {
  position: absolute;
  inset-inline-start: -999px;
}
.skip-link:focus {
  inset-inline-start: 16px;
  top: 16px;
}
```

```html
<body>
  <a class="skip-link" href="#main">Skip to content</a>
  <header>…</header>
  <main id="main">…</main>
</body>
```

Задайте целям ссылок внутри страницы `scroll-margin-top`, например `80px` под закреплённой шапкой, чтобы при переходе цель не оказалась за ней.

## Правила tabindex

- `tabindex="0"`: добавляет элемент в естественный порядок Tab. Берите лишь для своих элементов управления, которые сами не умеют получать фокус.
- `tabindex="-1"`: фокус доступен лишь из JavaScript через `el.focus()`. Подходит для заголовков, на которые переводят фокус, окон и частей составного элемента.
- Положительный `tabindex`: не берите. Он ломает порядок Tab на всей странице; исправьте порядок элементов в DOM.

### Перемещаемый tabindex

Составной элемент — вкладки, меню, панель инструментов, группа переключателей — занимает одно место в обходе Tab. У активной части `tabindex="0"`, у остальных `tabindex="-1"`. Стрелки двигают фокус и значение `0` вместе:

```tsx
<div role="tablist">
  {tabs.map((tab, i) => (
    <button
      role="tab"
      tabIndex={i === activeIndex ? 0 : -1}
      aria-selected={i === activeIndex}
      onKeyDown={handleArrowKeys} // ArrowLeft/ArrowRight move activeIndex, wrapping
    >
      {tab.label}
    </button>
  ))}
</div>
```

## Удержание и возврат фокуса

Окно должно удерживать фокус внутри себя. Современный способ — атрибут `inert` на всём, что находится за окном: он разом убирает фон из обхода Tab и из вспомогательных средств.

```tsx
// On open
document.getElementById("app-content").inert = true;
const dialog = dialogRef.current;
(dialog.querySelector("[autofocus]") ??
  dialog.querySelector("button, [href], input, select, textarea"))?.focus();

// On close
document.getElementById("app-content").inert = false;
triggerRef.current?.focus(); // always return focus to the element that opened it
```

Родной `<dialog>` с `showModal()` сам удерживает фокус, делает фон `inert` и закрывается по Escape. Выбирайте его. Если своё окно нельзя сделать через `<dialog>`, нужны `role="dialog"`, `aria-modal="true"` и доступное имя через `aria-labelledby` со ссылкой на заголовок. В обоих случаях:

- При открытии ставьте фокус на первый доступный элемент; в окне с подтверждением опасного действия — на наименее опасную кнопку.
- При закрытии возвращайте фокус на элемент, открывший окно. Если его больше нет, переведите фокус на ближайший подходящий блок.
- Задайте окну `overscroll-behavior: contain`, чтобы прокрутка внутри него не двигала страницу позади.

## Клавиши по ARIA APG

Родные элементы уже имеют нужное поведение. Для своих элементов его придётся написать. Роль — обещание: если задано `role="tab"`, человек ждёт всей модели клавиш для вкладок.

| Элемент | Клавиши |
| --- | --- |
| Окно | Tab и Shift+Tab ходят по кругу внутри; Escape закрывает |
| Вкладки | Стрелки ходят между вкладками по кругу; Tab переходит к панели; Home/End — к первой/последней |
| Кнопка меню | Enter/пробел/ArrowDown открывают и выбирают первый пункт; ArrowUp — последний; стрелки двигают выбор; Escape закрывает и возвращает фокус кнопке |
| Раскрываемый блок / «аккордеон» | Заголовок — `<button aria-expanded>`; Enter и пробел открывают и закрывают |
| Поле со списком | ArrowDown открывает список или переходит в него; Enter принимает выбор; Escape закрывает и возвращает фокус в поле; ввод фильтрует |
| Список выбора / группа радиокнопок | Стрелки меняют выбор; вся группа занимает одно место Tab |

Общие правила:

- Escape закрывает то, что открыто последним: подсказку, затем меню, затем окно.
- Внутри составного элемента ходят стрелками, а не Tab; Tab переходит между элементами.
- Для вкладок выберите способ включения: автоматический, когда панель появляется сразу при фокусе стрелкой, или ручной по Enter/пробелу, если смена панели дорогая.
- Enter отправляет форму из выбранного поля. В `<textarea>` Enter добавляет новую строку, а ⌘/Ctrl+Enter отправляет форму.

## Переходы между страницами в SPA

Переход на стороне клиента сам не сбрасывает фокус и ничего не сообщает. При смене страницы обновите `document.title` по новому месту, затем переведите фокус на `<h1>` нового экрана с `tabindex="-1"` или на `<main>`. При ходе назад или вперёд верните прошлое место прокрутки; при новом переходе прокрутите к началу.
