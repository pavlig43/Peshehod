# Программы чтения с экрана

Скрытый от глаз текст, области оповещений, всплывающие сообщения, описание картинок и SVG.

## Текст, скрытый лишь с экрана

Обычный класс `.sr-only` скрывает содержимое зрительно, но оставляет его доступным вспомогательным средствам:

```css
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0 0 0 0);
  clip-path: inset(50%);
  white-space: nowrap;
  border: 0;
}
```

Берите размер `1px`, а не `0`: часть программ чтения с экрана пропускает элементы нулевого размера. `white-space: nowrap` мешает словам слиться в одну строку без пробелов при чтении. Не берите для этой цели `display: none` или `visibility: hidden`: оба полностью скрывают текст от вспомогательных средств.

В Tailwind для этого есть `sr-only`. Для ссылки на пропуск к основному содержимому добавьте вариант, который открывает её при фокусе: `focus:not-sr-only` или смените положение в `:focus`.

Так можно передать словами то, что зрячий человек видит по картинке: `<span class="sr-only">Opens in new tab</span>`, подпись таблицы или имя кнопки с одним значком, если нельзя взять `aria-label`.

## Как сообщить о перемене

Идите по списку и берите первое подходящее правило:

1. **Фокус и так переходит туда** — например, в открытое окно или первое неверное поле после отправки. Больше ничего не нужно: смена фокуса сама сообщает о событии.
2. **Перемена относится к одному полю** — ошибка или счётчик знаков. Задайте полю `aria-describedby`: сообщение прозвучит вместе с полем.
3. **Сообщение не срочное и не относится к полю** — всплывающий текст, «Сохранено», число результатов, загрузка. Возьмите вежливую область оповещений или `role="status"`.
4. **Сообщение срочное и не относится к полю** — общая ошибка формы или конец сеанса. Возьмите `role="alert"`.

## Области оповещений

Они сообщают о переменах без перезагрузки страницы: всплывающем тексте, проверке формы, числе результатов, загрузке.

| Способ | Как сообщает | Для чего |
| --- | --- | --- |
| `role="status"` (= `aria-live="polite"` + `aria-atomic="true"`) | Ждёт паузы в чтении | Сообщения, «Сохранено», число результатов, ход загрузки |
| `role="alert"` (= `aria-live="assertive"` + `aria-atomic="true"`) | Прерывает чтение сразу | Лишь срочные ошибки и проблемы |

Правила надёжного оповещения:

- Для повторных вежливых сообщений заранее держите в DOM пустую постоянную область, затем меняйте её текст. Если вставить область вместе с текстом, программа может его не произнести.
- Динамически добавленный `role="alert"` чаще произносится, но поведение различается. Берите его лишь для срочных ошибок вне конкретного поля и проверьте нужные пары браузера и программы чтения.
- По умолчанию выбирайте вежливый режим. Частое `assertive` — распространённая ошибка: оно прерывает то, что человек читает.
- Пишите коротко и полно: `aria-atomic="true"` при каждой смене перечитывает всю область.
- Не переводите фокус на всплывающее сообщение. Озвучьте его и оставьте фокус там, где человек работает. Дайте сообщению долго оставаться или добавьте кнопку закрытия. Не прячьте единственный путь к действию в сообщении, которое само исчезнет.

```tsx
// Region rendered from the start, message injected later
<div role="status" className="sr-only">
  {statusMessage}
</div>
```

Во время загрузки задайте обновляемой области `aria-busy="true"`, вежливо сообщите «Загрузка…», а затем итог, например «Загружено, 12 результатов».

## aria-hidden

`aria-hidden="true"` скрывает элемент и всех его потомков от вспомогательных средств. Берите его для украшений и повторённого ради вида содержимого. Не ставьте на элемент с фокусом или его родителя: тогда Tab приведёт к месту, о котором программа чтения не знает. Если скрываете элемент управления, уберите его и из порядка обхода клавишей Tab.

## Описание картинок

Выбирайте текст по роли картинки, а не только по её внешнему виду:

| Роль | Alt | Пример |
| --- | --- | --- |
| Украшение или повтор соседнего текста | `alt=""`: пустой, но заданный | Логотип рядом с названием фирмы словами |
| Несёт сведения | Опишите добавленный смысл | `alt="QR-код билета"` |
| Служит ссылкой или кнопкой | Назовите действие или цель | Значок лупы → `alt="Поиск"`, а не `alt="лупа"` |
| Картинка с текстом | Точный текст; лучше взять настоящий текст | `alt="Скидка 50% на всё"` |
| Сложная схема или график | Короткий итог в `alt`, все данные рядом таблицей или текстом | `alt="Доход по кварталам, данные ниже"` |

Отсутствующий атрибут `alt` хуже пустого: программа чтения может произнести имя файла.

## SVG

- SVG для украшения: `aria-hidden="true"` и `focusable="false"` — второе нужно для старых Edge/IE; заголовок не нужен.
- SVG со смыслом прямо в коде: `role="img"` вместе с `aria-label="…"` либо `<title>` первым дочерним узлом со ссылкой через `aria-labelledby`.
- Для простого случая надёжнее всего `<img src="icon.svg" alt="…">`.

```tsx
// Decorative icon inside a labeled button
<button aria-label="Close">
  <svg aria-hidden="true" focusable="false">…</svg>
</button>

// Standalone meaningful icon
<svg role="img" aria-label="Verified account">…</svg>
```

## Видео и звук

Для готового видео нужны субтитры, для звука — текстовая запись. Не запускайте звук сам и всегда показывайте кнопки управления.
