# Области нажатия

Размеры целей, увеличение области нажатия без смены видимого размера и правила для пересечений.

## Размеры целей

Отделяйте обязательный минимум от более удобных размеров:

| Стандарт | Минимум |
| --- | --- |
| WCAG 2.5.8 (AA) | 24×24px — нижняя граница |
| WCAG 2.5.5 (AAA) | 44×44px |
| Apple HIG | 44×44pt |
| Material Design | 48×48dp |

WCAG 2.5.8 уровня AA требует область 24×24 CSS-пикселя либо одно из оговорённых исключений. Для главных кнопок советуйте область нажатия от 44px, а для настольного интерфейса — от 40px, если плотность макета это допускает. Меньший размер сам по себе не значит ошибку: сначала проверьте исключения для расстояния между целями, равных по действию элементов, встроенных в текст ссылок, элементов браузера и случаев, где размер важен для самого действия.

По исключению для расстояния маленькая цель допустима, если круг диаметром 24px с центром в её ограничивающей рамке не пересекает другую цель или такой же круг соседней маленькой цели. В простом случае между целями шириной 20px нужен зазор хотя бы 4px.

Видимый элемент может остаться маленьким: важен размер области нажатия. Если часть элемента выглядит доступной для нажатия, она должна реагировать на него целиком, без «мёртвых» зон. У флажка и его подписи должна быть общая цель.

## Увеличение области нажатия

Если видимый элемент меньше нужного размера, например флажок 20×20, расширьте область с помощью псевдоэлемента. Поместите его на обёртку `<label>` или `<button>`, а не на сам `<input>`: замещаемые элементы ненадёжно показывают `::before` и `::after`.

### Пример CSS

```css
/* Small checkbox with expanded 44px hit area, on the wrapping label */
.checkbox-label {
  position: relative;
  width: 20px;
  height: 20px;
}

.checkbox-label::after {
  content: "";
  position: absolute;
  top: 50%;
  left: 50%; /* physical centering: direction-independent */
  transform: translate(-50%, -50%);
  width: 44px;
  height: 44px;
}
```

### Пример Tailwind

```tsx
<button className="relative size-5 after:absolute after:top-1/2 after:left-1/2 after:size-11 after:-translate-1/2">
  <CheckIcon />
</button>
```

### Вариант через размер самого элемента

Если для элемента есть место, обойдитесь без псевдоэлемента: пусть сама рамка будет нужного размера. Тогда браузер также получит точную геометрию для прокрутки и жестов:

```css
.icon-button {
  min-width: 44px;
  min-height: 44px;
  display: inline-grid;
  place-items: center;
}
```

## Правило пересечений

Если расширенная область заходит на другой элемент управления, уменьшите псевдоэлемент. Сделайте область как можно больше, но не допускайте пересечений между областями двух элементов.

## Поведение при касании

- Добавьте `touch-action: manipulation` к элементам управления, чтобы на телефоне убрать задержку из-за двойного касания для увеличения страницы.
- Настройте `-webkit-tap-highlight-color` под стиль интерфейса вместо серой вспышки по умолчанию.
- Делайте цели крупнее и яснее показывайте, что на них можно нажать. Не стройте важные действия на крошечных ручках перетаскивания и узких зонах наведения.
