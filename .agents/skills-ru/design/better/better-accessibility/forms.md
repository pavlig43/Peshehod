# Формы

Подписи, автозаполнение, ошибки, типы полей и отправка формы.

## Подписи

У каждого поля должна быть подпись, связанная с ним в коде: `<label for>` указывает на `id` поля либо `<label>` оборачивает его. Подсказка внутри поля не заменяет подпись: она пропадает при вводе и часто имеет слабый контраст.

```html
<!-- Good: explicit association -->
<label for="email">Email</label>
<input id="email" type="email" autocomplete="email" />

<!-- Good: wrapping label, so label and control share one hit target -->
<label>
  <input type="checkbox" /> Send me updates
</label>
```

У подписи и поля должна быть общая область нажатия. Нажатие на «Send me updates» меняет флажок, а между текстом и флажком нет мёртвой зоны. Обязательные поля помечайте родным атрибутом `required` и видимым знаком; один раз поясните знак для всей формы, например «* — обязательное поле».

Если подсказка всё же нужна **помимо подписи**, покажите в ней образец формата: `placeholder="name@company.com"`.

## Сообщения об ошибках

Полный образец:

```html
<label for="email">Email</label>
<input
  id="email"
  type="email"
  autocomplete="email"
  aria-invalid="true"
  aria-describedby="email-error"
/>
<p id="email-error">Enter a valid email address.</p>
```

- Ставьте `aria-invalid="true"` на поле с ошибкой и убирайте его после правки.
- `aria-describedby` связывает поле с текстом ошибки: программа чтения с экрана прочтёт их вместе.
- Показывайте ошибку рядом с полем текстом или знаком. Одной красной рамки мало: цвет не должен быть единственным сигналом.
- При отправке переводите фокус на первое поле с ошибкой.
- Давайте отправить неполную форму, чтобы показать ошибки; не выключайте кнопку отправки до тех пор, пока всё не заполнено.
- Давайте вводить произвольный текст и проверяйте его после ввода. Не блокируйте набор и не убирайте знаки по мере печати. Перед проверкой удаляйте пробелы по краям: автозаполнение и подстановка текста могут их добавить.

## Автозаполнение и типы полей

Верное значение `autocomplete` и понятное имя поля позволяют заполнить форму одним нажатием. Для полей с данными пользователя это требование WCAG 1.3.5. Частые значения:

| Поле | `autocomplete` |
| --- | --- |
| Имя | `name` (или `given-name` / `family-name`) |
| Почта | `email` |
| Телефон | `tel` |
| Адрес | `street-address`, `address-line1`, `postal-code`, `country` |
| Карта | `cc-number`, `cc-exp`, `cc-csc`, `cc-name` |
| Вход | `username`, `current-password` |
| Регистрация / сброс пароля | `new-password` |
| Код двухэтапной проверки | `one-time-code` |

Если нужно, добавьте в начале раздел: `autocomplete="shipping street-address"`.

Верные `type` и `inputmode` открывают подходящую клавиатуру на телефоне:

| Данные | Что брать |
| --- | --- |
| Почта, URL, телефон | `type="email"`, `type="url"`, `type="tel"` |
| Разовый код, PIN, номер карты | `type="text" inputmode="numeric"` — поле остаётся текстовым, без кнопок изменения числа |
| Деньги и дробные числа | `type="text" inputmode="decimal"` |
| Настоящее число предметов | `type="number"` |

Для почты, кодов и имён учётных записей отключайте проверку орфографии: `spellcheck="false"`.

## Не мешайте средствам пользователя

- Не запрещайте вставку в `<input>` или `<textarea>`: люди вставляют пароли и разовые коды.
- Сохраняйте работу менеджеров паролей и автозаполнения кодов: настоящий `<form>`, верный `autocomplete`, никаких ложных полей.
- Не ставьте `user-scalable=no` или `maximum-scale=1` ради запрета увеличения поля на iOS. Вместо этого задайте тексту поля размер `16px` на телефоне; подробнее в `design-better-typography`.

## Отправка формы

- Держите кнопку отправки активной до начала запроса. Затем выключите её и покажите индикатор **рядом с прежней надписью**: «Сохранить» с индикатором, а не один индикатор. По надписи вспомогательные средства поймут, какая кнопка занята.
- Сообщайте об итоге: об успехе — через вежливую область живого текста. При ошибке поля переводите фокус на первое неверное поле: сам перенос фокуса сообщит об ошибке. `role="alert"` оставьте для общих ошибок формы, не связанных с полем; см. [screen-readers.md](screen-readers.md).
- Перед уходом со страницы предупреждайте о несохранённых правках. Не теряйте набранный текст при повторной отрисовке; при гидратации сохраняйте фокус и значение поля.
- Enter отправляет форму из любого выбранного поля ввода; из `<textarea>` отправка идёт по ⌘/Ctrl+Enter.
