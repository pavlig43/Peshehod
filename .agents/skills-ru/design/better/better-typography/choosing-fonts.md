# Выбор шрифтов

Как выбрать гарнитуру и формат файла и понять, почему шрифты выглядят по-разному.

## Выбор гарнитуры

Тип шрифта задаёт настроение ещё до выбора конкретной гарнитуры.

| Тип | Признаки | Для чего подходит |
| --- | --- | --- |
| С засечками | Небольшие штрихи на концах букв ведут взгляд вдоль строки | Длинные тексты, чтение статей |
| Без засечек | Чёткие ровные формы, которые хорошо видны в малом размере | Основной текст большинства интерфейсов: Helvetica, Inter, Geist |
| Моноширинный | Все знаки одной ширины, поэтому столбцы совпадают | Код, таблицы, данные в столбцах |
| Акцидентный | Нарисован для крупных заголовков | Рекламные заголовки, главный текст первого экрана |
| Рукописный | Похож на письмо от руки | Редкие декоративные детали |

В CSS для двух последних типов есть ключевые слова `cursive` и `fantasy`.

Слово «Display» в названии ещё не значит, что шрифт рассчитан лишь на крупный текст. Например, у SF Pro и Heldane есть варианты `Display` для больших размеров и `Text` для мелких. Берите вариант под тот размер, который задаёте.

### Правила

- Обычно чем меньше гарнитур, тем лучше. Больше трёх нужны редко. Страница продвижения может быть смелее по шрифтам, чем приложение.
- Это относится и к размерам и начертаниям. Они строят порядок чтения, но их избыток быстро портит разборчивость.
- Сочетайте разные характеры, а не похожие. Заголовок с засечками и основной текст без них ясно делят роли. Два почти одинаковых шрифта без засечек выглядят ошибкой.
- Тонкие начертания оставляйте крупному тексту. При размере ниже `18px` берите вес от `400`: штрихи Ultralight, Thin и Light (`100`–`300`) исчезают в обычном тексте и на экранах с низкой плотностью пикселей. Для текста от `28px` они допустимы, но проверьте их на фоне.

## Когда менять гарнитуру

Работа со шрифтами не требует замены гарнитуры. Опирайтесь на шрифты продукта, если в задаче прямо не просят их сменить. Не добавляйте платный или закрытый шрифт лишь ради пункта в списке проверки. Сглаживание, переносы строк и табличные цифры не отменяют выбор гарнитуры в проекте.

Если смену шрифта попросили: вид, привычный для macOS и iOS, даёт системный набор. Платный шрифт вроде Helvetica Now — решение для бренда; ему нужен запасной набор шрифтов.

```css
/* System-native macOS/iOS feel */
html {
  font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}

/* Commercial brand face with safe fallbacks */
html {
  font-family: "Helvetica Now", "Helvetica Neue", Arial, sans-serif;
}
```

## Форматы

| Формат | Пояснение |
| --- | --- |
| `.woff2` | Сжатие Brotli, широкая поддержка. Берите для сайтов. |
| `.woff` | Старый способ сжатия. Нужен лишь как запасной вариант для очень старых браузеров. |
| `.ttf` / `.otf` | Исходные форматы без сжатия для сайтов, файлы крупнее. Берите для настольных программ, если нет иного выхода. |

## Строение шрифта

| Термин | Смысл |
| --- | --- |
| Высота строчных (x-height) | Высота строчной `x` |
| Высота прописных | Высота заглавных букв |
| Базовая линия | Незримая линия, на которой стоят буквы |
| Верхний выносной элемент | Часть буквы выше высоты строчных |
| Нижний выносной элемент | Часть буквы ниже базовой линии |

Поэтому два шрифта с одним `font-size` могут казаться разными по размеру. Шрифт с большой высотой строчных выглядит крупнее.
