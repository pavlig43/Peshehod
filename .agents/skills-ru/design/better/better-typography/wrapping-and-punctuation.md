# Переносы и знаки препинания

Где начинаются и кончаются строки, как переносятся слова и какие знаки нужны в тексте.

## Длина строки

На длинной строке взгляду сложнее найти начало следующей. Для длинного текста берите около 60–75 знаков на строку.

Единицы измерения могут быть любыми. `65ch` задаёт ширину через символы: один `ch` равен ширине `0` в текущем шрифте. Предел в пикселях или rem тоже годится. При размере основного текста `16px` диапазон 60–75 знаков даёт около `560px`–`680px`, в зависимости от шрифта. Подходят, например, классы Tailwind `max-w-xl` (`576px`) и `max-w-2xl` (`672px`). Главное — задать предел и проверить длину строки. Если размер основного шрифта меняется, проверьте её снова.

## Выравнивание

`text-align` задаёт края строк. `text-align: justify` растягивает пробелы до ровных краёв с двух сторон. Иногда это уместно в макете статьи, но в большинстве интерфейсов лучше обойтись без него.

## Переносы

| Свойство | Для чего |
| --- | --- |
| `text-wrap: balance` | Равномерно раскладывает текст по строкам |
| `text-wrap: pretty` | Не оставляет одно короткое слово на последней строке |
| `overflow-wrap: break-word` | Переносит длинные слова, ссылки и ID до выхода за границы блока |
| `white-space: nowrap` | Держит подписи и метки в одной строке, когда перенос портит вид |

Для заголовков берите `balance`, для описаний — `pretty`: вместе они дают лучший вид. Для длинного текста пропустите оба: браузеры всё равно перестают применять `balance` после нескольких строк, а выравнивание целого абзаца тратит место и мешает чтению.

## Обрезка текста

- Одна строка: `text-overflow: ellipsis` вместе с `overflow: hidden` и `white-space: nowrap`.
- Несколько строк: `line-clamp` позволяет задать их число перед многоточием.

Обрезка скрывает текст. Если пропущенная часть важна, покажите полный текст ещё где-то: во всплывающей подсказке или развёрнутом виде.

## Регистр букв

`text-transform` меняет вид регистра, не меняя сам текст. Пишите естественно и управляйте внешним видом через CSS. Тогда смена оформления не потребует переписывать подписи.

## Подходящие знаки

Знаки с клавиатуры не всегда лучше:

| Вместо | Берите |
| --- | --- |
| Прямые кавычки `"..."` | Кавычки нужной формы вокруг текста; в коде оставьте прямые |
| Дефис в промежутке | Короткое тире: `2010–2020` |
| Два дефиса для вставки | Длинное тире одним знаком |
| Три точки `...` | Знак многоточия `…` |
| Обычный пробел в `16 px` | `&nbsp;`, чтобы число и единица не разошлись |
| Перенос слова в случайном месте | `&shy;`, чтобы отметить допустимое место переноса |

## Текст на разных языках

- Задайте атрибут `lang`, чтобы браузер выбрал нужные кавычки, переносы и произношение.
- Задайте `dir` на границе документа или фрагмента, где меняется направление письма. Отражение макета и таблица логических свойств описаны в `design-better-layout`.

Два уточнения для текста с разным направлением письма:

- **Длинный абзац выравнивайте по его языку.** Фрагмент в одну-две строки следует направлению всего интерфейса. Абзац из трёх и более строк — направлению своего письма: английский абзац остаётся выровненным от начала строки слева направо даже в интерфейсе справа налево. Для этого задайте самому абзацу верные `lang` и `dir` и `text-align: start`.
- **Никогда не переворачивайте цифры.** Их порядок одинаков при любом направлении письма: номер телефона и число «541» читаются в том же порядке. Браузер сам применяет двунаправленный алгоритм Unicode. Не переставляйте цифры вручную; если соседний текст справа налево мешает числу с текстом, оберните такой фрагмент в `<bdi>`.
