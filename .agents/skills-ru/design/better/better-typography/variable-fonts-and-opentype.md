# Переменные шрифты и OpenType

Что ещё умеет файл шрифта, кроме вывода букв, и как задать эти возможности через CSS.

## Обычный и переменный шрифт

- **Обычный шрифт:** один вес и один стиль в каждом файле. Обычный, средний и жирный — три файла.
- **Переменный шрифт:** целый ряд значений в одном файле. Работает любое значение в заданном пределе, например `font-weight: 589`.

Переменный шрифт не всегда лучше. Для одного-двух начертаний обычные файлы могут быть меньше. Если нужны несколько весов, оптических размеров или особых осей, переменный файл обычно удобнее.

## Загружайте нужные веса и стили

Если шрифт не содержит запрошенный вес или стиль, браузер может нарисовать его сам. Лучше загрузить те начертания, которые нужны дизайну. Запрещайте искусственные начертания лишь после проверки всей цепочки запасных шрифтов и всех случаев смыслового выделения. `none` разом запрещает подделку веса, стиля, капителей, верхних и нижних индексов. Если нужного настоящего начертания нет, разница между ними может пропасть.

```css
.brand-wordmark {
  /* Safe only after this isolated treatment is verified */
  font-synthesis: none;
}
```

Для основного текста и интерфейса оставляйте искусственные начертания включёнными, если не проверили, что набор шрифтов покрывает каждую нужную форму. Если мешает лишь один вид, задайте отдельное свойство `font-synthesis-weight`, `font-synthesis-style` или другое вместо общего запрета.

## Оси

У переменного шрифта есть настройки с четырёхбуквенными метками. Доступны лишь оси, которые добавил автор шрифта.

| Ось | Метка | Что меняет |
| --- | --- | --- |
| Вес | `wght` | Толщину штрихов, как `font-weight` |
| Оптический размер | `opsz` | Детали и интервалы под размер показа |
| Ширина | `wdth` | Ширину знаков |
| Наклон | `slnt` | Угол наклона |
| Особая | Например, `GRAD` у Roboto Flex | То, что заложил автор |

В переменном файле Inter доступны лишь `wght` и `opsz`.

Оптические размеры существовали и до переменных шрифтов. Многие гарнитуры выпускают их отдельными файлами: Heldane Text прочнее и шире для обычного чтения, Heldane Display тоньше в деталях для крупных букв.

## Свойства лучше сырых меток осей

Если для настройки есть свойство CSS, берите его. `font-weight` продолжит работать со запасным обычным шрифтом; `font-variation-settings` в этом случае тихо перестанет действовать. Сырые метки оставьте для особых осей без своего свойства:

```css
/* Good: common axes use the properties */
.heading {
  font-weight: 650;
  font-optical-sizing: auto;
}

/* Good: custom axis with no property of its own */
.heading-grade {
  font-variation-settings: "GRAD" 80;
}

/* Bad: weight via raw tag breaks on fallback fonts */
.heading {
  font-variation-settings: "wght" 650;
}
```

## Функции OpenType

OpenType — стандарт почти всех новых шрифтов. Его функции — встроенные доп. возможности. В отличие от осей они одинаково работают в обычных и переменных шрифтах. Доступны лишь функции, включённые автором.

| Метка | Функция |
| --- | --- |
| `tnum` | Табличные цифры: все одной ширины |
| `zero` | Перечёркнутый ноль, чтобы отличать `0` от `O` |
| `liga` | Лигатуры: соединение пар вроде «fi» в один знак |
| `ss01`–`ss20` | Наборы вариантов начертания по номерам |
| `cv01`–`cv99` | Варианты отдельных знаков по номерам |

Правило то же, что для осей: берите свойства `font-variant-*`, а `font-feature-settings` оставьте для меток без своего свойства.

```css
/* Good: common features use the properties */
.price {
  font-variant-numeric: tabular-nums;
}

/* Good: slashed zero via the property too */
.id {
  font-variant-numeric: slashed-zero;
}

/* Good: niche feature with no property of its own */
.logo {
  font-feature-settings: "ss01" 1;
}
```

Табличные цифры важны для меняющихся чисел: без них цифры разной ширины и макет прыгает при обновлении.

## Капители, верхние и нижние индексы

- **Капители:** прописные буквы меньшего размера. Настоящие капители включают через `font-variant-caps`.
- **Верхние индексы** стоят выше строки, например 2 в x², **нижние** — ниже, например ₂ в H₂O. Верные знаки задают через `font-variant-position`.

Для обоих видов нужные знаки должны входить в шрифт.

## Наборы стилей и варианты знаков

`ss01` — первый набор вариантов начертания; `cv11` — вариант отдельного знака под номером 11. Смысл номера зависит от шрифта, поэтому метки числовые, а не словесные. Проверьте описание гарнитуры. В Inter `ss01` даёт открытые цифры, а `cv11` — одноэтажную `a`.
