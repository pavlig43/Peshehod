# Детали и доступность текста

Подчёркивания, выделение, формы, украшение букв и нижние границы разборчивости.

## Подчёркивания

Браузер сам выбирает место линии. Иногда она слишком близка к буквам, пересекает нижние части или выглядит тонкой. Берите положение и толщину из данных шрифта:

```css
a {
  text-underline-position: from-font;
  text-decoration-thickness: from-font;
}
```

Линия не обязана быть сплошной. `text-decoration-style` может сделать её точечной, штриховой или волнистой. Точки часто подсказывают, что у слова есть пояснение — например, у сокращения или термина:

```css
abbr {
  text-decoration: underline dotted;
}
```

Параметры можно настроить вручную:

```css
a {
  text-decoration-thickness: 1px;
  text-underline-offset: 3px;
  text-decoration-skip-ink: auto;
  text-decoration-color: var(--color-gray-1000);
  transition: text-decoration-color 200ms ease-out;
}

a:hover {
  text-decoration-color: var(--color-gray-1200);
}
```

У настоящего подчёркивания надёжно меняется плавно лишь цвет. Если нужен иной эффект, сделайте свою линию отдельным элементом вместо `text-decoration` и анимируйте его нужным способом.

## Выделение

- `::selection` меняет фон и цвет выделенного текста. Это тонкий способ добавить фирменный стиль, но сохраните контраст.
- По умолчанию давайте выделять весь текст, включая подписи самого приложения. Люди копируют названия, ID, ошибки и значения там, где дизайнер этого не ожидал.
- Ставьте `user-select: none` лишь на отдельную поверхность с перетаскиванием или жестом, где случайное выделение мешает действию. Не задавайте его всему интерфейсу или только ради сходства с родным приложением.
- `::target-text` оформляет фразу, к которой ведёт общая ссылка.
- Custom Highlight API оформляет выбранные вами части текста, например найденные слова, без лишней разметки.

## Формы и редактируемый текст

- `::placeholder` оформляет подсказку в пустом поле.
- `caret-color` задаёт цвет мигающего курсора. На этом обычно стоит остановиться: свой курсор сделать очень трудно и редко стоит усилий без особого эффекта.

### Увеличение поля на iOS

Если выбрать поле с текстом мельче `16px`, Safari увеличит всю страницу. Это помощь тем, кому трудно читать при вводе: `16px` — обычный размер веб-текста, а меньший Safari считает слишком мелким.

```tsx
// Good: 16px on mobile, smaller from the sm breakpoint up
<input className="text-base sm:text-sm" type="email" />
```

Не пытайтесь исправить это через метатег `maximum-scale=1`. Safari не соблюдает его предел при увеличении жестом, но другие браузеры соблюдают и мешают людям увеличивать страницу. Это нарушает WCAG 1.4.4. Размер поля, который зависит от ширины экрана, решает задачу без вреда для доступности.

## Украшение текста

| Свойство | Эффект |
| --- | --- |
| `::first-letter` | Буквица; широкая поддержка |
| `::first-line` | Оформляет только первую строку |
| `initial-letter` | Задаёт размер буквицы; поддержка ограничена, в Firefox пока нет |
| `background-clip: text` | Обрезает фон или градиент по форме букв |
| `-webkit-text-stroke` | Обводит буквы; работает в новых браузерах, несмотря на префикс |
| `text-shadow` | Как `box-shadow`, но по форме букв |

Если обводка рисует линии внутри букв, причина в шрифте: она идёт по каждому контуру, а в переменных шрифтах наложенные формы обычно не сливаются. У обычных статичных шрифтов такой проблемы нет.

## Размеры

Текст должен выдерживать настройки читателя: увеличение страницы, крупный шрифт в браузере, смену высоты строки и межбуквенного интервала.

| Текст | Размер |
| --- | --- |
| Отправная точка для длинного текста | Около `16px`; проверьте с настоящим шрифтом и шириной строки |
| Отправная точка для полей и меню | Около `14px` |
| Подписи | `13px` |
| Нижняя граница | Меньше `12px` — лишь редко |

Если текст кажется бледным, измерьте контраст готовой пары текста и фона по правилам `design-better-colors` и найдите нужный норматив в `design-better-accessibility`. Меняйте цвета проекта только как осознанное решение по дизайну, если пользователь не просил исправить контраст.

## Сглаживание шрифта

На macOS текст выглядит тяжелее, чем задумывалось. Задайте сглаживание один раз на корневом элементе, чтобы оно действовало на весь текст. Класс Tailwind `antialiased` ставит оба свойства:

```css
html {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
}
```

```tsx
<html lang="en">
  <body class="font-sans antialiased">
    <main>{children}</main>
  </body>
</html>
```
