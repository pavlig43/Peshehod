# Значки интерфейса

Толщина линий, состояния, размер и направление — детали, от которых зависит, насколько естественно значок смотрится рядом с текстом.

## Согласуйте толщину значка с весом текста

Значок возле надписи должен казаться таким же плотным, как буквы. Очень тонкий значок у полужирного текста выглядит сломанным, тяжёлый у обычного — слишком громким.

| Текст рядом | Толщина линии значка на сетке 24px |
| --- | --- |
| Обычный (400), 14–16px | `1.5px` |
| Средний и полужирный (500–600) | `2px` |
| Жирный (700) или отдельный важный значок | `2.5px` |

```html
<!-- Good: stroke tuned to the label weight -->
<button class="flex items-center gap-2 font-semibold">
  <PlusIcon stroke-width="2" class="size-4" />
  New project
</button>

<!-- Bad: default 1.5px stroke against a bold label -->
<button class="flex items-center gap-2 font-bold">
  <PlusIcon stroke-width="1.5" class="size-4" />
  New project
</button>
```

Ещё два правила единого вида:

- **Один подход к толщине на одном участке.** Не смешивайте на одной панели наборы значков с разной толщиной линий. Если выбранный набор сам даёт варианты толщины, подберите её к тексту. Иначе сохраните толщину набора, а важность покажите размером или цветом.
- **Размер значка подбирайте к высоте прописных букв.** Возле текста обычно подходит `1em`–`1.25em`, чтобы текст и значок росли вместе.

## Один SVG с цветом по состоянию

Не храните отдельные файлы значка для обычного состояния, наведения, выбора и выключения. Нарисуйте один SVG с `currentColor`, а цвет пусть задаёт CSS:

```html
<!-- Good: one asset, states are CSS -->
<svg fill="none" stroke="currentColor" stroke-width="2">…</svg>
```

```css
.icon-button { color: oklch(0.552 0.016 285.938); }
.icon-button:hover { color: oklch(0.21 0.006 285.885); }
.icon-button[aria-pressed="true"] { color: oklch(0.623 0.188 259.815); }
.icon-button:disabled { opacity: 0.4; }
```

```html
<!-- Tailwind -->
<button class="text-zinc-500 hover:text-zinc-900 aria-pressed:text-blue-600 disabled:opacity-40">
  <BookmarkIcon />
</button>
```

Жёстко заданная заливка внутри SVG, например `fill="#666"`, ломает такой способ. При добавлении значка замените её на `currentColor`.

## Контур обычно, заливка при выборе

Если в наборе есть контурный и залитый варианты, применяйте их как пару состояний, а не случайно:

| Вариант | Когда брать |
| --- | --- |
| Контур | Обычное состояние в панелях, строках списка и рядом с текстом |
| Заливка | Выбрано или включено: текущая вкладка, закладка, отметка «нравится» |

```tsx
// Good: variant communicates state
<TabIcon variant={isActive ? "solid" : "outline"} />

// Bad: filled icons everywhere, so the active tab has no state signal
<TabIcon variant="solid" />
```

Смена вариантов — анимация значка по ситуации. Точные значения для плавной смены см. в [animations.md](animations.md).

## Рисуйте под итоговый размер

Значок, удачный при 48px, может слиться в пятно при 16px. Тонкие внутренние линии, тесные просветы и мелкая фактура при уменьшении размываются или дают «лесенку».

- Проверьте каждый значок в самом малом размере, в котором его покажут, часто `16px`. Он должен остаться узнаваемым.
- Для малых размеров берите простые рисунки, а не просто уменьшайте сложные.
- Попадайте в сетку пикселей при итоговом размере. Значок 16px, нарисованный на сетке 24px и уменьшенный с дробным множителем, выглядит размытым. Берите родные сетки набора: `16`, `20`, `24`.
- Всегда берите SVG, а не растровую картинку, чтобы значок оставался чётким при любой плотности экрана.

## Значки при письме справа налево

При `dir="rtl"` отражайте значки, чей смысл зависит от направления чтения. Остальные оставляйте как есть:

| Отразить | Не отражать |
| --- | --- |
| Стрелки назад и вперёд, уголки в меню | Логотипы и знаки бренда |
| Знаки текстовых блоков: выравнивание, списки, отступы | Галочки |
| Волны от динамика — они идут по направлению чтения | Предметы: часы, чашки, карандаши |
| Направленный знак «Отправить» | Воспроизведение медиа: «играть» и «назад» связаны с ходом записи и остаются слева направо |

```css
/* Good: mirror only direction-dependent icons */
[dir="rtl"] .icon-directional {
  scale: -1 1;
}
```

```html
<!-- Tailwind -->
<ChevronRightIcon class="icon-directional rtl:-scale-x-100" />
```

Составной значок проверяйте по частям: метка или перечёркивающая линия могут остаться на своём месте, когда основную форму нужно отразить. Доступные имена кнопок без текста описаны в `design-better-accessibility`.
