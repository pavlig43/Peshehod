# Анимации

Анимации, которые можно прервать, переходы появления и исчезновения, контекстные анимации значков и умеренное использование движения.

## Анимации, которые можно прервать

Пользователь может передумать прямо во время взаимодействия. Если анимацию нельзя прервать, интерфейс кажется сломанным.

### CSS-переходы и ключевые кадры

| | CSS-переходы | CSS-анимации с ключевыми кадрами |
|---|---|---|
| **Поведение** | Перестраиваются к последнему состоянию | Проигрываются по фиксированному сценарию |
| **Можно прервать** | Да, цель меняется прямо во время анимации | Нет, анимация запускается сначала |
| **Применение** | Изменения состояния при взаимодействии (наведение, переключение, открытие и закрытие) | Последовательности, которые проигрываются один раз (появление, загрузка) |
| **Длительность** | Фиксирована; при изменении цели меняется значение, но не отсчёт времени | Фиксированный сценарий, при повторном запуске проигрывается сначала |

```css
/* Хорошо: переход для переключателя можно прервать */
.drawer {
  transform: translateX(-100%);
  transition: transform 200ms ease-out;
}
.drawer.open {
  transform: translateX(0);
}

/* Повторное нажатие во время анимации плавно меняет её направление */
```

```css
/* Плохо: ключевые кадры для интерактивного элемента */
.drawer.open {
  animation: slideIn 200ms ease-out forwards;
}

/* При закрытии во время анимации элемент дёргается или запускается сначала */
```

**Правило:** для интерактивных элементов всегда предпочитайте CSS-переходы. Ключевые кадры оставьте для последовательностей, которые проигрываются один раз.

## Появление: разделение и последовательный запуск

Используйте этот приём для редких последовательных появлений, когда порядок помогает показать иерархию: например, при первой загрузке главного блока страницы, экрана успеха или пустого состояния. Разделите крупный контейнер на смысловые части и анимируйте каждую отдельно. Не задавайте задержку для обычных взаимодействий: наведения на строки, нажатий клавиш или многократного переключения вкладок.

### По шагам

1. **Разделите** содержимое на смысловые группы: заголовок, описание, кнопки.
2. **Задайте задержку** около 100 мс между группами.
3. **Для заголовков** можно разделить текст на слова с задержкой около 80 мс между ними.
4. **Сочетайте** `opacity`, `blur` и `translateY` для эффекта появления.

### Пример кода

```tsx
// Motion (Framer Motion): последовательное появление
function PageHeader() {
  return (
    <motion.div
      initial="hidden"
      animate="visible"
      variants={{
        visible: { transition: { staggerChildren: 0.1 } },
      }}
    >
      <motion.h1
        variants={{
          hidden: { opacity: 0, y: 12, filter: "blur(4px)" },
          visible: { opacity: 1, y: 0, filter: "blur(0px)" },
        }}
      >
        Добро пожаловать
      </motion.h1>

      <motion.p
        variants={{
          hidden: { opacity: 0, y: 12, filter: "blur(4px)" },
          visible: { opacity: 1, y: 0, filter: "blur(0px)" },
        }}
      >
        Описание страницы.
      </motion.p>

      <motion.div
        variants={{
          hidden: { opacity: 0, y: 12, filter: "blur(4px)" },
          visible: { opacity: 1, y: 0, filter: "blur(0px)" },
        }}
      >
        <Button>Начать</Button>
      </motion.div>
    </motion.div>
  );
}
```

### Последовательность только на CSS

```css
.stagger-item {
  opacity: 0;
  transform: translateY(12px);
  filter: blur(4px);
  animation: fadeInUp 400ms ease-out forwards;
}

.stagger-item:nth-child(1) { animation-delay: 0ms; }
.stagger-item:nth-child(2) { animation-delay: 100ms; }
.stagger-item:nth-child(3) { animation-delay: 200ms; }

@keyframes fadeInUp {
  to {
    opacity: 1;
    transform: translateY(0);
    filter: blur(0);
  }
}
```

## Анимации исчезновения

Исчезновение должно быть мягче и менее заметным, чем появление. Внимание пользователя переключается на следующий элемент — не отвлекайте его.

### Незаметное исчезновение (рекомендуется)

```tsx
// Небольшое постоянное смещение по Y указывает направление и не отвлекает
<motion.div
  exit={{
    opacity: 0,
    y: -12,
    filter: "blur(4px)",
    transition: { duration: 0.15, ease: "easeOut" },
  }}
>
  {content}
</motion.div>
```

### Полное исчезновение (если важен контекст)

```tsx
// Полное смещение: используйте, когда важно показать расположение
// (например, карточка возвращается в список или закрывается боковая панель)
<motion.div
  exit={{
    opacity: 0,
    x: "-100%",
    transition: { duration: 0.2, ease: "easeOut" },
  }}
>
  {content}
</motion.div>
```

### Хороший и плохой варианты

```css
/* Хорошо: незаметное исчезновение */
.item-exit {
  opacity: 0;
  transform: translateY(-12px);
  transition: opacity 150ms ease-out, transform 150ms ease-out;
}

/* Плохо: резкое исчезновение перетягивает внимание */
.item-exit {
  opacity: 0;
  transform: translateY(-100%) scale(0.5);
  transition: all 400ms ease-out;
}

/* Иногда правильно: удалить элемент сразу, если движение ничего не объясняет */
.item-exit {
  display: none;
}
```

**Основные правила:**

- Используйте небольшое фиксированное смещение `translateY` (например, `-12px`) вместо высоты всего контейнера.
- Сохраните небольшое движение, чтобы показать, куда переместился элемент.
- Исчезновение должно быть короче появления (150 мс против 300 мс).
- Используйте незаметное исчезновение, если оно помогает понять расположение элементов. Удаляйте элемент сразу, если движение ничего не сообщает, действие часто повторяется или включено уменьшение анимации.

## Контекстная анимация значков

Если значки появляются или исчезают в ответ на контекст (при наведении или изменении состояния), анимируйте `opacity`, `scale` и `blur`, а не просто переключайте видимость.

### Пример Motion

В примере используется пакет `motion`. Если в проекте установлен `framer-motion`, импортируйте те же API из `"framer-motion"`. Не смешивайте установленный пакет с путём импорта другого пакета.

```tsx
import { AnimatePresence, motion } from "motion/react";

function IconButton({ isActive, icon: Icon }) {
  return (
    <button>
      <AnimatePresence mode="popLayout">
        <motion.span
          key={isActive ? "active" : "inactive"}
          initial={{ opacity: 0, scale: 0.25, filter: "blur(4px)" }}
          animate={{ opacity: 1, scale: 1, filter: "blur(0px)" }}
          exit={{ opacity: 0, scale: 0.25, filter: "blur(4px)" }}
          transition={{ type: "spring", duration: 0.3, bounce: 0 }}
        >
          <Icon />
        </motion.span>
      </AnimatePresence>
    </button>
  );
}
```

### Переходы CSS без Motion

Если в проекте не используется Motion (Framer Motion), оставьте оба значка в DOM и плавно меняйте их прозрачность с помощью CSS-переходов. Поскольку ни один значок не удаляется из DOM, появление и исчезновение анимируются плавно.

Приём состоит в том, чтобы расположить один значок поверх другого абсолютно. При смене состояния прозрачность плавно меняется: появляющийся значок увеличивается от `0.25`, а исчезающий уменьшается до `0.25`; оба размываются и становятся прозрачными.

```tsx
function IconButton({ isActive, ActiveIcon, InactiveIcon }) {
  return (
    <button>
      <div className="relative">
        <div
          className={cn(
            "absolute inset-0 flex items-center justify-center",
            "transition-[opacity,filter,scale] duration-300",
            "ease-[cubic-bezier(0.2,0,0,1)]",
            isActive
              ? "scale-100 opacity-100 blur-0"
              : "scale-[0.25] opacity-0 blur-[4px]"
          )}
        >
          <ActiveIcon />
        </div>
        <div
          className={cn(
            "transition-[opacity,filter,scale] duration-300",
            "ease-[cubic-bezier(0.2,0,0,1)]",
            isActive
              ? "scale-[0.25] opacity-0 blur-[4px]"
              : "scale-100 opacity-100 blur-0"
          )}
        >
          <InactiveIcon />
        </div>
      </div>
    </button>
  );
}
```

Значок в обычном потоке (`InactiveIcon`) задаёт размер элемента. Абсолютно расположенный значок (`ActiveIcon`) накладывается поверх и не влияет на поток.

### Как выбрать между Motion и CSS

| | Motion (Framer Motion) | CSS-переходы (оба значка в DOM) |
|---|---|---|
| **Появление** | Да | Да |
| **Исчезновение** | Да, через `AnimatePresence` | Да, перекрёстное изменение прозрачности; значок не удаляется из DOM |
| **Пружинная физика** | Да | Нет; используйте `cubic-bezier(0.2, 0, 0, 1)` как приближение |
| **Когда использовать** | В проекте уже есть `motion` или `framer-motion` | Нет зависимости от Motion или нужно сохранить небольшой размер сборки |

**Правило:** проверьте `package.json` проекта. Если установлен `motion`, импортируйте из `"motion/react"`; если `framer-motion` — из `"framer-motion"`. Если установлены оба, ориентируйтесь на импорты в компоненте или ближайших компонентах. Если нет ни одного, используйте CSS-переходы; не добавляйте зависимость только ради анимации значков.

### Когда анимировать значки

| Анимировать | Не анимировать |
|-------------|----------------|
| Значки кнопок действий, появляющиеся при наведении | Статичные значки навигации |
| Значки состояния (воспроизведение → пауза, лайк → лайк поставлен) | Декоративные значки |
| Значки в контекстных панелях инструментов | Постоянно видимые значки |
| Индикаторы загрузки и успеха | Подписи рядом со значками |

**Важно:** для контекстных анимаций значков используйте только следующие точные значения:

- `scale`: от `0.25` до `1` (не используйте `0.5` или `0.6`);
- `opacity`: от `0` до `1`;
- `filter`: от `"blur(4px)"` до `"blur(0px)"`;
- `transition`: `{ type: "spring", duration: 0.3, bounce: 0 }`; значение **bounce всегда должно быть `0`**, не `0.1` и не другое.

## Уменьшение при нажатии

Лёгкое уменьшение кнопки при нажатии даёт тактильный отклик. Всегда используйте `scale(0.96)`. Не задавайте значение меньше `0.95`: эффект будет чрезмерным. Используйте CSS-переход, который можно прервать: если пользователь отпустит кнопку до конца анимации, она плавно вернётся в исходное состояние.

Такое поведение нужно не каждой кнопке. Добавьте компоненту кнопки свойство `static`, отключающее уменьшение там, где движение отвлекает.

### Пример CSS

```css
.button {
  transition-property: scale;
  transition-duration: 150ms;
  transition-timing-function: ease-out;
}

.button:active {
  scale: 0.96;
}
```

### Пример Tailwind

```tsx
<button className="transition-transform duration-150 ease-out active:scale-[0.96]">
  Нажми меня
</button>
```

### Пример Motion

```tsx
<motion.button whileTap={{ scale: 0.96 }}>
  Нажми меня
</motion.button>
```

### Шаблон со свойством static

Вынесите класс уменьшения в переменную и применяйте его условно в зависимости от свойства `static`:

```tsx
const tapScale = "active:not-disabled:scale-[0.96]";

function Button({ static: isStatic, className, children, ...props }) {
  return (
    <button
      className={cn(
        "transition-transform duration-150 ease-out",
        !isStatic && tapScale,
        className,
      )}
      {...props}
    >
      {children}
    </button>
  );
}

// Использование
<Button>Нажми меня</Button>      {/* уменьшается при нажатии */}
<Button static>Отправить</Button> {/* без уменьшения */}
```

## Не запускайте анимацию при загрузке страницы

Задайте `initial={false}` для `AnimatePresence`, чтобы анимация появления не запускалась при первом отображении. Элементы, уже находящиеся в обычном состоянии, не должны анимированно появляться при загрузке страницы — только при последующих изменениях состояния.

### Когда это подходит

```tsx
// Хорошо: значок не анимируется при монтировании, только при изменении состояния
<AnimatePresence initial={false} mode="popLayout">
  <motion.span
    key={isActive ? "active" : "inactive"}
    initial={{ opacity: 0, scale: 0.25, filter: "blur(4px)" }}
    animate={{ opacity: 1, scale: 1, filter: "blur(0px)" }}
    exit={{ opacity: 0, scale: 0.25, filter: "blur(4px)" }}
  >
    <Icon />
  </motion.span>
</AnimatePresence>
```

Подходит для смены значков, переключателей, вкладок, сегментированных элементов управления — всего, что имеет исходное состояние при загрузке страницы.

### Когда это нарушает поведение

Не используйте `initial={false}`, если компонент полагается на свойство `initial` для начальной анимации появления, например, для последовательного появления главного блока или состояния загрузки. Без начальной анимации элемент не появится должным образом.

```tsx
// Плохо: initial={false} полностью отменит последовательное появление блока
<AnimatePresence initial={false}>
  <motion.div initial="hidden" animate="visible" variants={...}>
    ...
  </motion.div>
</AnimatePresence>
```

Перед применением обновите страницу целиком и убедитесь, что компонент отображается правильно.

## Умеренное использование движения

Движение — ограниченный ресурс, а не украшение. Перед добавлением анимации проверьте три правила:

- **Не добавляйте особые анимации для частых действий.** Анимация, которую пользователь постоянно запускает (каждое нажатие клавиши, наведение на строку, переключение вкладки в рабочем инструменте), каждый раз отвлекает внимание. Оставьте выразительное движение для редких моментов: первой загрузки экрана, успешного действия и пустого состояния. Частые действия должны получать мгновенный отклик или едва заметный переход (`opacity`/`background-color` не дольше 150 мс).
- **Анимация не должна быть единственным способом передать состояние.** Любое изменение состояния, о котором сообщает анимация, должно быть заметно и без неё: по цвету, значку или подписи. Пользователи с настройкой уменьшенного движения и те, кто моргнул, тоже должны понять, что произошло.
- **Краткость и точность важнее эффектности.** Если короткая и небольшая анимация сообщает то же самое, используйте её. Если сомневаетесь, сократите длительность, сохранив ясность.

```css
/* Хорошо: частое наведение вызывает короткий переход */
.row:hover {
  background-color: var(--surface-hover);
  transition: background-color 100ms ease-out;
}

/* Плохо: каждое наведение заново запускает полное появление */
.row:hover .row-icon {
  animation: bounceIn 500ms;
}
```

Поддержка настройки `prefers-reduced-motion` описана в навыке `design-better-accessibility`; применяйте её ко всем анимациям из этого файла.
