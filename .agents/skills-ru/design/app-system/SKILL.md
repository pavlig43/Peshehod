# Основная дизайн-система приложения

Это главный источник правил для внешнего вида приложения. Он задаёт тёплый редакционный стиль, фирменные цвета и сочетание шрифтов, по которым узнают продукт.

Точные правила для цветов, шрифтов, компоновки и элементов интерфейса есть в соседнем [README.md](README.md).

## Главные принципы

- **Тёплая основа:** фон кремового оттенка (`#faf9f5`), без чисто белого цвета.
- **Фирменный акцент:** коралловый (`#cc785c`) для главных действий и важных выделений.
- **Шрифты в редакционном стиле:** заголовки набраны брусковым Copernicus с плотным межбуквенным интервалом, основной текст — гуманистическим гротеском Inter.
- **Глубина макетов продукта:** тёмные поверхности (`#181715`) для показа интерфейса продукта и кода.
- **Широкие отступы:** ритм разделов по 96px и внутренние поля карточек по 32px.

Полные таблицы дизайн-токенов и набор элементов см. в [README.md](README.md).
