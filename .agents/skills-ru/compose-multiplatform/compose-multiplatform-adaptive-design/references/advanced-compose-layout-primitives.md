# Средства Compose для гибкой разметки

## Содержание

1. FlexBox.
2. Отслеживание видимости.
3. Линии выравнивания.
4. Внутренние размеры.
5. Как выбрать.

## 1. FlexBox

Берите FlexBox для небольшой группы элементов разной величины, когда важны перенос на новую строку, растяжение и сжатие. Не берите его для очень длинных списков: он не загружает элементы по мере нужды.

Подходящие случаи:

- гибкие панели инструментов;
- группы меток фильтров;
- группы действий разного размера.

Главные параметры:

- контейнер: `direction`, `wrap`, `justifyContent`, `alignItems`, `alignContent`, `rowGap`, `columnGap`;
- элемент: `basis`, `grow`, `shrink`, `alignSelf`, `order`.

Правило выбора: для больших наборов данных берите `LazyColumn` или `LazyVerticalGrid`, а для переноса небольшой меняющейся группы — FlexBox вместо старой потоковой разметки.

## 2. Отслеживание видимости

Следите за видимостью прокручиваемого содержимого, чтобы запускать аналитику, раннюю загрузку, автопоказ и действия, похожие на события жизненного цикла.

Главные API:

- `Modifier.onVisibilityChanged(...)`;
- `Modifier.onLayoutRectChanged(...)` — более низкий уровень.

Важные параметры `onVisibilityChanged`:

- `minFractionVisible` — сработать лишь после появления нужной доли площади;
- `minDurationMs` — сработать лишь после достаточно долгой видимости.

Ставьте модификаторы в осмысленном порядке. Если видимая область должна включать отступы, поставьте модификатор видимости до модификатора отступа.

## 3. Линии выравнивания

Они нужны, когда родитель выравнивает детей по смысловой точке, например по базовой линии текста или своей отметке графика.

Подходящие случаи:

- выравнивание текста по базовой линии у разных компонентов;
- привязка подписи к нужной отметке данных на графике.

Как сделать:

- объявить свой `AlignmentLine`;
- передать значения из своего `Layout` через `alignmentLines = mapOf(...)`;
- прочитать у родителя через `placeable[MyAlignmentLine]`.

## 4. Внутренние размеры

Они решают случаи, когда ограничения родителя зависят от свойств содержимого ребёнка.

Пример: вертикальный разделитель между двумя текстами должен быть высотой с самый высокий текст. Поставьте `Modifier.height(IntrinsicSize.Min)` на родительский ряд.

Правила:

- Запрос внутреннего размера не равен двойному измерению ребёнка.
- Берите этот API лишь при нужде: частые запросы могут быть дорогими.
- В своём `Layout` или модификаторе переопределяйте методы внутренних размеров, если стандартный ответ неверен.

## 5. Быстрый выбор

- Нужен перенос небольшой группы с растяжением и сжатием — FlexBox.
- Нужно событие при появлении элемента — `onVisibilityChanged`.
- Родитель должен выравнивать детей по смысловой точке — линии выравнивания.
- Размер родителя зависит от содержимого ребёнка до окончательного измерения — внутренние размеры.
