# Открытый API для описания звука

## Создание

- `audioProgram { tempo; control; include; instrument; musicTrack; sfx; musicBus; sfxBus }`
- `audioProgramFragment { ... }` — для повторно используемых описаний.
- Значения: `Int.ms`, `Double.seconds`, `Int.hz`, `Double.hz`, `MidiNote.of(0..127)`.
- Типизированные имена команд: `AudioControlName`, `SfxName`.
- Имена пишутся строчными буквами через подчёркивание и начинаются с буквы.

## Источники и обработка голоса

- Осцилляторы: синусоида, треугольная, пилообразная, прямоугольная и импульсная волны.
- Шум: белый, розовый и коричневый с явно заданным `Long` в качестве начального числа.
- Аддитивные `partial`, при нужде — со своей огибающей ADSR; частотная модуляция и вибрато.
- Огибающая ADSR `envelope`.
- Фильтры нижних, верхних и средних частот, в том числе со слежением за частотой ноты через `noteFrequency(ratio, offsetHz)`.
- Искажение и снижение разрядности.
- Посылы на задержку и реверберацию; связанный стереокомпрессор и лимитер на `musicBus`/`sfxBus`.

Параметр может быть константой, значением от элемента управления, синусоидальным низкочастотным сигналом, сглаженным шумом с заданным начальным числом, частотой ноты или произведением таких значений. Диапазон каждого результата должен быть допустимым для места, куда он передаётся. Сила ноты `AudioNote.Pitched` конечна и лежит в `0f..1f`.

## Ритмические схемы

Используйте `pure`, `sequence`, `stack`, `euclidean`, `choose`, `degrade`, `fast`, `slow`, `shift`, `repeat`, `every`, `swing` и `humanize` с заданным начальным числом. `humanizedNotes` даёт воспроизводимые изменения силы нот. `tonalScale` даёт небольшой проверенный набор распространённых ладов. Части `arrangement` для дорожки могут повторять схему, менять её высоту или выключать целые циклы без замены планировщика. Случайные операции требуют явного начального числа и дают воспроизводимый результат.

## Во время работы

У `MiniAppAudio` четыре команды: `playMusic`, `stopMusic`, `playSfx`, `setControl`. Обрабатывайте `Accepted` и `Rejected(reason, diagnostics)`. Воспроизведение может быть отклонено или подавлено из-за видимости, настроек музыки и эффектов, закрытия сеанса или недоступности звуковой подсистемы.

Экземпляр `MiniAppAudio` принадлежит одному сеансу MiniApp. Хост закрывает его при завершении жизненного цикла. Игра вызывает `stopMusic` лишь для своей намеренной паузы или перехода.

Полная справка для автора: `docs/miniapp/audio/getting-started.md`.
